# Системы счислений

Система счисления — это способ записи чисел с помощью символов (цифр), подчиняющийся определённым правилам.

Существует два основных типа систем счисления:

1. Позиционные системы:

* Значение числа зависит от положения цифры в записи
* Примеры: десятичная, двоичная, восьмеричная, двенадцатеричная, шестнадцатеричная
* Преимущество: простота арифметических операций
* Пример: числа 45 и 54 имеют разное значение из-за разного положения цифр

2. Непозиционные системы:

* Значение числа не зависит от положения цифр
* Примеры: римская, древнеегипетская, вавилонская
* Недостаток: сложность в выполнении арифметических действий
* Пример: в римской системе I всегда означает 1, X всегда 10, независимо от их позиции в числе

Так же, существует третий тип систем счисления - смешанные.&#x20;

Смешанные системы счисления — это особый вид систем, где числа, записанные в системе с одним основанием (P), представляются с помощью цифр другой системы с меньшим основанием (Q), где Q < P. Такие системы называются (Q-P)-ичными со старшим основанием P и младшим основанием Q. (часы, денежные знаки)

### **Перевод чисел из любой системы счисления в десятичную**

Механизм перевода числа из любой системы счисления в десятичную основан на представлении числа в развёрнутой форме. Вот пошаговый алгоритм:

1. Определение компонентов:

* Знак числа (положительный или отрицательный)
* Основание системы счисления (n)
* Разряды числа (позиции цифр)
* Величины в каждом разряде

2. Принцип перевода:

* Каждая цифра числа умножается на основание системы счисления в степени, соответствующей позиции этой цифры
* Степени считаются справа налево, начиная с нуля
* Для дробной части используются отрицательные степени

Формула для расчёта:\
Число = (цифра₁ × основание^позиция₁) + (цифра₂ × основание^позиция₂) + …

### **Перевод чисел из десятичной системы счисления в любую другую**

Для перевода чисел из десятичной системы счисления в любую другую пользуются следующим алгоритмом:

Алгоритм перевода из десятичной системы в любую другую методом последовательного деления:

1. Для целой части числа:

* Последовательно делим исходное число на основание новой системы счисления
* Продолжаем деление до тех пор, пока частное не станет меньше делителя
* **Записываем остатки от каждого деления в обратном порядке (снизу вверх)**
* Переводим полученные остатки в алфавит новой системы счисления (если необходимо)

2. Для дробной части числа:

* Последовательно умножаем дробную часть на основание новой системы
* Отделяем целую часть полученного произведения
* Продолжаем умножение дробной части до достижения нужной точности
* Записываем целые части произведений в прямом порядке (сверху вниз)
* Переводим полученные числа в алфавит новой системы счисления

3. Для чисел с целой и дробной частью:

* Сначала переводим целую часть по алгоритму (1)
* Затем переводим дробную часть по алгоритму (2)
* В итоговом числе целую часть отделяем от дробной запятой

**Метод таблички для работы с сетями**

Метод менее универсальный но более быстрый. Со временем можно всё будет делать в уме. Работает только с числами до 255.

Метод таблички для перевода чисел между двоичной и десятичной системами особенно удобен при работе с IP-адресами и масками подсетей.

1. Для перевода двоичного числа в десятичное:

2. Для перевода десятичного числа в двоичное:

* В верхней строке опять пишем степени двойки
* Если число больше или равно числу в столбце, ставим 1 и вычитаем это число
* Если меньше - ставим 0
* Продолжаем, пока число не станет 0
