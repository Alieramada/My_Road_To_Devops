### Условные операторы для чисел и строк 

Для чисел (используются внутри \[ ] или \[\[ ]]):

bash\
if \[ $a -eq $b ]; then # равно (equal)\
if \[ $a -ne $b ]; then # не равно (not equal)\
if \[ $a -lt $b ]; then # меньше (less than)\
if \[ $a -le $b ]; then # меньше или равно (less or equal)\
if \[ $a -gt $b ]; then # больше (greater than)\
if \[ $a -ge $b ]; then # больше или равно (greater or equal)\
Пример:

bash\
a=5\
b=10\
if \[ $a -lt $b ]; then\
echo "a < b"\
fi\


Для строк (используются внутри \[ ] или \[\[ ]]):

bash\
if \[ "$str1" = "$str2" ]; then # строки равны\
if \[ "$str1" != "$str2" ]; then # строки не равны\
if \[ -z "$str" ]; then # строка пуста (zero length)\
if \[ -n "$str" ]; then # строка не пуста (non-zero)\
Пример:

bash\
name="Alice"\
if \[ "$name" = "Alice" ]; then\
echo "Привет, Алиса!"\
fi\


Команда shift\
Сдвигает позиционные параметры ($1, $2, ...) влево.

Пример: Обработка аргументов скрипта с опциями.

```
while [ $# -gt 0 ]; do
  case "$1" in
    -f|--file)
      filename="$2"
      shift 2  # Сдвигаем на 2 позиции (-f и значение)
      ;;
    -v|--verbose)
      verbose=1
      shift    # Сдвигаем на 1 позицию
      ;;
    *)
      echo "Неизвестный аргумент: $1"
      exit 1
      ;;
  esac
done
```

\
Как работает shift:

bash

Исходные аргументы: $1 = -f, $2 = file.txt, $3 = -v

shift # Теперь $1 = file.txt, $2 = -v\
shift 2 # Теперь $1 = -v\

Скрипт: greet.sh -n Alice --verbose

```
name=""
verbose=0

while [ $# -gt 0 ]; do
  case "$1" in
    -n|--name)
      name="$2"
      shift 2
      ;;
    --verbose)
      verbose=1
      shift
      ;;
    *)
      echo "Ошибка: Неизвестный аргумент $1"
      exit 1
      ;;
  esac
done

if [ -n "$name" ]; then
  echo "Привет, $name!"
  [ $verbose -eq 1 ] && echo "(Режим verbose)"
else
  echo "Укажите имя с помощью -n <имя>"
fi
```
