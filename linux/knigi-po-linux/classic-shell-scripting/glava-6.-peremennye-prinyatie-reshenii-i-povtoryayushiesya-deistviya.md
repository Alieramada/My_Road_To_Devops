# Глава 6. Переменные, принятие решений и Повторяющиеся действия

Переменные необходимы для нетривиальных программ. Они поддерживают значения, полезные в качестве данных и для управления состоянием программы. Поскольку командная оболочка в основном является языком обработки строк, вы можете многое сделать со строковыми значениями переменных командной оболочки. Однако, поскольку для этого необходимы математические операции, оболочка POSIX также предоставляет механизм для выполнения арифметических действий с переменными оболочки.

Функции управления потоком создают язык программирования: практически невозможно выполнить какую-либо реальную работу, если все, что у вас есть, - это императивные инструкции. В этой главе рассматриваются возможности командной оболочки для тестирования результатов и принятия решений на основе этих результатов, а также циклического выполнения.

Наконец, функции позволяют группировать инструкции, связанные с задачей, в одном месте, что упрощает выполнение этой задачи из нескольких точек вашего скрипта.

## 6.1 Переменные и арифметика

Переменные оболочки похожи на переменные любого обычного языка программирования. Они сохраняют значения до тех пор, пока они вам не понадобятся. Мы описали основы имен и значений переменных оболочки в разделе “Переменные” . Кроме того, сценарии и функции командной строки имеют позиционные параметры, что является модным термином для обозначения “аргументов командной строки”.

В сценариях командной строки часто используются простые арифметические операции, например, добавление единицы к переменной при каждом выполнении цикла. Оболочка POSIX предоставляет обозначение для встроенной арифметики, называемое арифметическим расширением. Оболочка вычисляет арифметические выражения внутри $((...)) и помещает результат обратно в текст команды.

### 6.1.1 Назначение переменных и окружение

Назначение и использование переменных оболочки были рассмотрены в разделе “Переменные” \[2.5.2]. В этом разделе представлены остальные подробности.

Две похожие команды обеспечивают управление переменными. Команда readonly делает переменные доступными только для чтения; присвоения им становятся запрещенными. Это хороший способ создания символьных констант в командной оболочке программы:

```
hours_per_day=24 seconds_per_hour=3600 days_per_week=7                 Assign values
readonly hours_per_day seconds_per_hour days_per_week                 Make read-only
```

**export, readonly**

_**Использование:**_

export name\[=word] …&#x20;

export –p&#x20;

readonly name\[=word] …

readonly–p

_**Цель:**_

Экспорт изменяет или печатает среду. переменные, доступные только для чтения, становятся неизменяемыми.

_**Основные опции:**_

–p

Выведите название команды, а также имена и значения всех экспортируемых (доступных только для чтения) переменных таким образом, чтобы командная оболочка могла перечитать выходные данные для повторного создания среды (настройки только для чтения).

_**Поведение:**_

С параметром –p обе команды выводят свое имя и все переменные и значения , которые экспортируются или доступны только для чтения, соответственно. В противном случае они применяют соответствующий атрибут к именованным переменным.

_**Предостережения:**_

Версии /bin/sh во многих коммерческих Unix-системах (к сожалению) до сих пор недоступны. Совместимый с POSIX. Таким образом, форма присвоения переменной для экспорта и только для чтения не работает. Для обеспечения максимальной переносимости используйте:

```
FOO=somevalue
export FOO
BAR=anothervalue
readonly BAR
```

Гораздо чаще используется команда export, которая помещает переменные в среду. Среда - это просто список пар имя-значение, доступный каждой запущенной программе. Новые процессы наследуют среду от своей родительской и могут изменять ее перед созданием собственных дочерних процессов. Команда export добавляет новые переменные в среду:

```bash
PATH=$PATH:/usr/local/bin                                                 Update PATH
export PATH                                                                 Export it
```

Оригинальная оболочка Bourne shell требовала использования двухэтапного процесса, т.е. назначение и экспорт или только чтение выполняются отдельно (как мы только что показали). Стандарт POSIX позволяет выполнять назначение и команду одновременно:

```bash
readonly hours_per_day=24 seconds_per_hour=3600 days_per_week=7
export PATH=$PATH:/usr/local/bin
```

Команда export также может быть использована для печати текущей среды:

```bash
$ export -p                                         Print current environment
export CDPATH=":/home/tolstoy"
export DISPLAY=":0.0"
export ENV="/home/tolstoy/.kshrc"
export EXINIT="set ai sm"
export FCEDIT="vi"
...
```

Переменные могут быть добавлены в среду программы, не оказывая постоянного влияния на среду оболочки или последующие команды. Это делается путем добавления префикса к имени команды и аргументам:

```bash
PATH=/bin:/usr/bin awk '...' file1 file2
```

Это изменяет значение PATH только для выполнения одной команды awk. Однако все последующие команды будут видеть текущее значение PATH в своей среде.

Команда export только добавляет переменные в среду. Команда env может использоваться для удаления переменных из среды программы или для временного изменения значений переменных среды:

```bash
env -i PATH=$PATH HOME=$HOME LC_ALL=C awk '...' file1 file2
```

Параметр –i инициализирует среду, т.е. отбрасывает все унаследованные значения, передавая программе только те переменные, которые указаны в командной строке.

Команда unset удаляет переменные и функции из запущенной оболочки. По умолчанию она удаляет переменные, хотя это можно сделать явно с помощью -v:

```bash
unset full_name                         Remove the full_name variable
unset -v first middle last              Remove the other variables
```

Используйте unset -f для удаления функций:

```
who_is_on ( ) {                                    Define a function
 who | awk '{ print $1 }' | sort -u                Generate sorted list of users
}
...
unset -f who_is_on
```

В ранних версиях оболочки не было функций или команды unset. В POSIX добавлена опция –f для удаления функций, а затем добавлена опция –v для симметрии с –f.

_**env**_

_**Использование:**_

env \[ –i ] \[ var=value … ] \[ command\_name \[ arguments … ] ]

_**Цель:**_

Обеспечить детальный контроль над средой, наследуемой command\_name , когда она запускается env.

_**Основные опции:**_

–i

Игнорировать унаследованную среду, используя только переменные и значения, указанные в командной строке

_**Поведение:**_

Если не указано command\_name, выведите имена и значения всех переменных в среде. В противном случае используйте присвоения переменных в командной строке для изменения унаследованной среды, прежде чем вызывать command\_name. С параметром –i env полностью игнорирует унаследованную среду и использует только предоставленные переменные и значения.

_**Предостережения:**_

При печати env не обязательно правильно указывает значения переменных среды для повторного ввода в командную строку. Для этого используйте export -p.



**unset**

_**Использование:**_

unset \[ –v ] variable …&#x20;

unset –f function …

_**Цель:**_

Удалить переменные и функции из текущей оболочки.

_**Основные опции:**_

–f Отмените установку (удалите) именованных функций.&#x20;

–v Отмените установку (удалите) именованных переменных. Это действие по умолчанию без каких-либо опций.

_**Поведение:**_

При отсутствии параметров аргументы обрабатываются как имена переменных, а указанные переменные удаляются. То же самое происходит с параметром –v. При использовании параметра –f аргументы обрабатываются как имена функций и функции удаляются.

{% hint style="info" %}
Присвоение myvar= не удаляет myvar, а просто присваивает ему значение нулевой строки. В отличие от этого, unset myvar полностью удаляет его. Это различие проявляется в различных расширениях “is the variable set” и “is the variable set, но не null”, описанных в следующем разделе
{% endhint %}

### 6.1.2 Расширение параметров

Расширение параметров - это процесс, посредством которого командная оболочка предоставляет значение переменной для использования в программе; например, в качестве значения для новой переменной или в качестве части или всего аргумента командной строки. Простейшая форма, несомненно, знакома:

```
reminder="Time to go to the dentist!"                     Save value in reminder
sleep 120 Wait two minutes
echo $reminder Print message
```

Оболочка имеет более сложные формы, которые полезны в более специализированных ситуациях. Все эти формы заключают имя переменной в фигурные скобки (${variable}), а затем добавляют дополнительный синтаксис, указывающий оболочке, что делать. Фигурные скобки сами по себе также полезны, если вам нужно сразу после имени переменной ввести символ, который в противном случае мог бы быть интерпретирован как часть имени:

```
reminder="Time to go to the dentist!"                         Save value in reminder
sleep 120 Wait two minutes
echo _${reminder}_                     Print message with underscores, for emphasis
```

{% hint style="info" %}
По умолчанию неопределенные переменные расширяются до нулевой (пустой) строки. Таким образом, небрежное программирование может привести к катастрофе: `rm -fr /$MYPROGRAM If MYPROGRAM isn't set, disaster strikes!`Таким образом, как всегда, стоит программировать тщательно!
{% endhint %}

#### 6.1.2.1 Операторы расширения

Первая группа операторов обработки строк проверяет наличие переменных и позволяет заменять значения по умолчанию при определенных условиях. Они перечислены в Таблица 6-1.

| Оператор            | Замена                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ${varname:-word}    | <p>Если varname существует и не равно null, верните его значение; в противном случае верните word. </p><p></p><p>Цель: Вернуть значение по умолчанию, если переменная не определена</p>                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ${varname:=word}    | <p>Если varname существует и не равно null, верните его значение; в противном случае присвойте ему значение word и затем верните его значение. </p><p></p><p>Цель: Присвоить переменной значение по умолчанию, если оно не определено. </p><p></p><p>Пример: ${count:=0} устанавливает значение count равным 0, если оно не определено.</p>                                                                                                                                                                                                                                                                                                  |
| ${varname:?message} | <p>Если varname существует и не равно null, верните его значение; в противном случае выведите varname: message и прервите текущую команду или сценарий. При пропуске message параметр сообщения по умолчанию будет равен null или не установлен. Однако обратите внимание, что интерактивные оболочки не обязательно прерывают работу. (Поведение в разных оболочках различается; будьте осторожны!) </p><p></p><p>Цель: отлавливать ошибки, возникающие из-за того, что переменные не определены. </p><p></p><p>Пример: ${count:?"не определено!"} выводит count: не определено! и завершает работу, если значение count не определено.</p> |
| ${varname:+word}    | <p>Если varname существует и не равно null, верните word; в противном случае верните null. </p><p></p><p>Цель: Проверить существование переменной.</p><p></p><p>Пример: ${count:+1} возвращает 1 (что может означать “истина”), если count определен</p>                                                                                                                                                                                                                                                                                                                                                                                     |

Двоеточие (:) в каждом из операторов в таблице 6-1 необязательно. Если двоеточие опущено, то измените “существует и не равно null” на “существует” в каждом определении; т.е. оператор проверяет только существование.

Операторы, приведенные в таблице 6.1, используются в оболочке Bourne уже более 20 лет. POSIX стандартизировала дополнительные операторы для сопоставления с образцом и удаления текста из значений переменных. Классическое применение новых операторов сопоставления с образцом заключается в удалении компонентов имен путей, таких как префиксы каталогов и суффиксы имен файлов. Имея это в виду, в таблице 6.2, помимо перечисления операторов оболочки, соответствующих шаблону , также приведены примеры, показывающие, как работают все операторы. Для этих примеров предположим, что переменная path имеет значение /home/tolstoy/mem/long.file.name.

| Оператор               | Замена                                                                                                                          |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| ${variable#pattern}    | Если шаблон совпадает с началом значения переменной, удалите самую короткую часть, которая соответствует, и верните оставшуюся. |
| Example: ${path#/\*/}  | Result: tolstoy/mem/long.file.name                                                                                              |
| ${variable##pattern}   | Если шаблон совпадает с началом значения переменной, удалите самую длинную часть, которая соответствует, и верните оставшуюся.  |
| Example: ${path##/\*/} | Result: long.file.name                                                                                                          |
| ${variable%pattern}    | Если шаблон совпадает с концом значения переменной, удалите самую короткую часть, которая соответствует, и верните оставшуюся.  |
| Example: ${path%.\*}   | Result: /home/tolstoy/mem/long.file                                                                                             |
| ${variable%%pattern}   | Если шаблон совпадает с концом значения переменной, удалите самую длинную часть, которая соответствует, и верните оставшуюся.   |
| Example: ${path%%.\*}  | Result: /home/tolstoy/mem/long                                                                                                  |

Их может быть трудно запомнить, поэтому вот удобный мнемонический прием: # соответствует лицевой стороне, потому что числовые знаки предшествуют цифрам; % соответствует задней стороне, потому что знаки процента следуют за цифрами. Другая мнемоническая схема основана на типичном расположении (в Во всяком случае, в США) из клавиш # и % на клавиатуре. Относительно друг друга # находится слева , а % - справа.

Здесь используются два шаблона: /\*_/, который соответствует чему-либо между двумя косыми чертами, и .\*_, который соответствует точке, за которой следует что-либо.

Наконец, POSIX стандартизировал оператор определения длины строки: ${#variable} возвращает длину значения переменной $ в символах:

```
$ x=supercalifragilisticexpialidocious         A famous word with amazing properties
$ echo There are ${#x} characters in $x
There are 34 characters in supercalifragilisticexpialidocious
```

#### 6.1.2.2 Позиционные параметры

Так называемые позиционные параметры представляют аргументы командной строки shell-скрипта. Они также представляют аргументы функции внутри shell-функций. Отдельные аргументы обозначаются целыми числами. По историческим причинам, если число больше девяти, его следует заключать в фигурные скобки:

```bash
echo first arg is $1
echo tenth arg is ${10}
```

Вы также можете применить все операторы проверки значений и сопоставления с образцом из предыдущего раздела к позиционным параметрам:

```
filename=${1:-/dev/tty}                     Use argument if given, /dev/tty if not
```

Специальные “переменные” предоставляют доступ к общему количеству переданных аргументов и ко всем аргументам сразу:

$#

Предоставляет общее количество аргументов, передаваемых в сценарий или функцию командной строки. Это полезно для создания циклов (описанных далее в разделе “Циклирование” \[6.4]) для обработки параметров и аргументов. Например:

```bash
while [ $# != 0 ] $#               decremented by shift, loop will terminate
do
 case $1 in
 ... Process first argument
 esac
 shift Shift first argument away (see later in text)
done
```

$\*, $@

Представляет все аргументы командной строки одновременно. Они могут использоваться для передачи аргументов командной строки программе, запускаемой скриптом или функцией.

"$\*"

Представляет все аргументы командной строки в виде одной строки. Эквивалентно "$1 $2 …". Первый символ $IFS используется в качестве разделителя для различных значений при создании строки. Например:

```
printf "The arguments were %s\n" "$*"
```

"$@"

Представляет все аргументы командной строки в виде отдельных строк. Эквивалентно "$1" "$2" .... Это лучший способ передать аргументы другой программе, поскольку при этом сохраняются все пробелы, встроенные в каждый аргумент. Например:

```
lpr "$@"                                                             Print each file
```

Команда set служит нескольким целям. (Полная информация приведена ниже в разделе “Команда set” \[7.9.1].) При вызове без опций она устанавливает значение позиционных параметров, отбрасывая все ранее существовавшие значения:

```
set -- hi there how do you do         The – – ends options; "hi" starts new arguments
```

Команда shift “удаляет” позиционные параметры из списка, начиная с левого. После выполнения shift исходное значение $1 исчезает навсегда и заменяется старым значением $2. Значение $2, в свою очередь, становится прежним значением $3 и так далее. Значение $# уменьшается на единицу. shift принимает необязательный аргумент, который указывает, сколько аргументов нужно удалить из списка. Обычный сдвиг - это то же самое, что и сдвиг 1. Вот аннотированный пример, который связывает все эти вещи воедино:

```
$ set -- hello "hi there" greetings             Set new positional parameters
$ echo there are $# total arguments             Print the count
there are 3 total arguments

$ for i in $*                                   Loop over arguments individually
> do echo i is $i
> done
i is hello                                      Note that embedded whitespace was lost
i is hi
i is there
i is greetings

$ for i in $@                                  Without quotes, $* and $@ are the same
> do echo i is $i
> done
i is hello
i is hi
i is there
i is greetings

$ for i in "$*"                                 With quotes, $* is one string
> do echo i is $i
> done
i is hello hi there greetings

$ for i in "$@"                                 With quotes, $@ preserves exact argument values
> do echo i is $i
> done
i is hello
i is hi there
i is greetings

$ shift Lop off the first argument

$ echo there are now $# arguments               Prove that it's now gone
there are now 2 arguments

$ for i in "$@"
> do echo i is $i
> done
i is hi there
i is greetings
```

#### 6.1.2.3 Специальные переменные

Помимо специальных переменных, которые мы только что рассмотрели, таких как $# и $\*, оболочка имеет ряд дополнительных встроенных переменных. Некоторые из них также имеют односимвольные, неалфавитные имена. Имена других состоят исключительно из прописных букв.

В таблице 6-3 перечислены переменные, встроенные в оболочку и влияющие на ее поведение. ### 6.1.3 Арифметическое разложение

Арифметические операторы оболочки эквивалентны их аналогам в языке C. Приоритет и ассоциативность такие же, как в C. В таблице 6-4 показаны поддерживаемые арифметические операторы в порядке от самого высокого приоритета к самому низкому. Хотя некоторые из них являются специальными символами (или содержат их), нет необходимости экранировать их обратной косой чертой, поскольку они соответствуют синтаксису $((...)). Этот синтаксис действует подобно двойным кавычкам, за исключением того, что встроенную двойную кавычку не нужно экранировать (см. “Цитирование” \[7.7]).

| Оператор                            | Значение                                               | Сопряжённость |
| ----------------------------------- | ------------------------------------------------------ | ------------- |
| ++ --                               | Приращение и уменьшение, префикс и постфикс            | Слева направо |
| +-!\~                               | Унарные плюс и минус; логическое и побитовое отрицание | Справа налево |
| <p></p><p>*/ %</p>                  | Умножение, деление и остаток                           | Слева направо |
| <p></p><p>+-</p>                    | Сложение и вычитание                                   | Слева направо |
| << >>                               | Сдвиг битов влево и вправо                             | Слева направо |
| < <= > >=                           | Сравнения                                              | Слева направо |
| = = !=                              | Равенство и не равенство                               | Слева направо |
| &                                   | Побитовое И                                            | Слева направо |
| ^                                   | Побитовое исключающее ИЛИ                              | Слева направо |
| \|                                  | Побитовое ИЛИ                                          | Слева направо |
| &&                                  | Логическое И                                           | Слева направо |
| \|\|                                | Логическое ИЛИ                                         | Слева направо |
| ?:                                  | Условное выражение                                     | Справа налево |
| = += -= \*= /= %= &= ^= <<= >>= \|= | Операторы присваивания                                 | Справа налево |

Круглые скобки могут использоваться для группировки подвыражений. Как и в C, операторы сравнения (<, <=, >, >=, = =,и !=) выдают числовой результат, который действует как значение истинности: 1 для true и 0 для false.

Например, $((3 > 2)) имеет значение 1; $(( (3 > 2) || (4 <= 1) )) также имеет значение 1, поскольку по крайней мере одно из двух подвыражений истинно.

Для логических операторов AND и OR любое ненулевое значение считается истинным:

```
echo $((3 && 4))                                             Both 3 and 4 are "true"
1
```

Такое использование ненулевого значения в качестве “истинного” применимо практически ко всем языкам, производным от C, таким как C++, Java и awk.

Если вы знакомы с C, C++ или Java, то вам будут знакомы операторы, перечисленные в таблице 6-4. Если вы не знакомы, то некоторые из них заслуживают небольшого пояснения.

Формы присваивания обычных операторов являются удобным сокращением для более традиционного способа обновления переменной. Например, во многих языках вы можете написать x=x+2, чтобы добавить 2 к x. Оператор += позволяет сделать это более компактно: $((x += 2)) добавляет 2 к x и сохраняет результат обратно в x

Поскольку сложение и вычитание единицы являются такими частыми операциями, операторы ++ и -- предоставляют еще более упрощенный способ их выполнения. Как вы можете догадаться, ++ добавляет единицу, а -- вычитает единицу. Это унарные операторы. Давайте кратко рассмотрим, как они работают:

```bash
$ i=5
$ echo $((i++)) $i
5 6
$ echo $((++i)) $i
7 7
```

Что здесь происходит? В обоих случаях значение i увеличивается на единицу. Однако значение, возвращаемое оператором, зависит от его расположения относительно переменной , с которой выполняется операция. Постфиксный оператор (тот, который выполняется после переменной) возвращает старое значение переменной как результат выражения, а затем увеличивает переменную. Напротив, префиксный оператор, который стоит перед переменной, сначала увеличивает переменную, а затем возвращает новое значение. Оператор -- работает так же, как и ++, но он уменьшает переменную на единицу, а не увеличивает ее.

{% hint style="info" %}
Операторы ++ и -- необязательны: соответствующие реализации не обязаны их поддерживать. bash и ksh93 поддерживают их. Стандарт позволяет реализации поддерживать дополнительные операторы. Все версии ksh93 поддерживают оператор запятой на языке Си, а последние версии поддерживают возведение в степень с помощью \*\*. bash также поддерживает оба этих параметра. Стандарт описывает арифметику только с использованием постоянных значений. Когда сначала выполняется вычисление параметра, такого как $i, арифметический вычислитель видит только постоянные значения. На практике все оболочки, поддерживающие $((...)) позволяет вам указывать имя переменной без префикса с $
{% endhint %}

Согласно POSIX, арифметика выполняется с использованием длинных целых чисел со знаком C. ksh93 поддерживает арифметику с плавающей запятой, но вам не следует полагаться на это в портативных программах.
