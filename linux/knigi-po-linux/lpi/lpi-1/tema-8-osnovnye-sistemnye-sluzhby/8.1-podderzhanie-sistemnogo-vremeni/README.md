# 8.1 Поддержание системного времени

## Ключевые области знаний

* Установка системной даты и времени.
* Установка аппаратных часов на правильное время в формате UTC.
* Настройка правильного часового пояса.
* Базовая настройка NTP с помощью ntpd и chrony.
* Знание о том, как использовать сервис pool.ntp.org.
* Знание команды ntpq.

## Неполный список используемых файлов, терминов и утилит

* `/usr/share/zoneinfo/`
* `/etc/timezone`
* `/etc/localtime`
* `/etc/ntp.conf`
* `/etc/chrony.conf`
* `date`
* `hwclock`
* `timedatectl`
* `ntpd`
* `ntpdate`
* `chronyc`
* `pool.ntp.org`
