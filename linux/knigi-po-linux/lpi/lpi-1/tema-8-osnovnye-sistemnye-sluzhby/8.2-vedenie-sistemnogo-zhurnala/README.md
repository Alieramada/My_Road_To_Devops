# 8.2 Ведение системного журнала

## Ключевые области знаний

* Базовая настройка rsyslog.
* Понимание стандартных средств, приоритетов и действий.
* Запрос журнала systemd.
* Фильтрация данных журнала systemd по таким критериям, как дата, служба или приоритет.
* Настройка постоянного хранения данных журнала systemd и размера журнала.
* Удаление старых данных журнала systemd.
* Получение данных журнала systemd из резервной системы или копии файловой системы.
* Понимание взаимодействия rsyslog с systemd-journald.
* Настройка logrotate.
* Понимание syslog и syslog-ng.

## Неполный список используемых файлов, терминов и утилит

* `/etc/rsyslog.conf`
* `/var/log/`
* `logger`
* `logrotate`
* `/etc/logrotate.conf`
* `/etc/logrotate.d/`
* `journalctl`
* `systemd-cat`
* `/etc/systemd/journald.conf`
* `/var/log/journal/`
