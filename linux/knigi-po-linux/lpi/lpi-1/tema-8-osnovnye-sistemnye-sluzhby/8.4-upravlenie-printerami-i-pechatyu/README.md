# 8.4 Управление принтерами и печатью

## Ключевые области знаний

* Базовая настройка CUPS (для локальных и удалённых принтеров).
* Управление пользовательскими очередями печати.
* Устранение общих проблем с печатью.
* Добавление и удаление заданий из настроенных очередей печати.
