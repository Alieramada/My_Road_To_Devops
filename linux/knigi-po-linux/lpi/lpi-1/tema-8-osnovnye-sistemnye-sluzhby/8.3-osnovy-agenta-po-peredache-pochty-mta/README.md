# 8.3 Основы агента по передаче почты (MTA)

## Ключевые области знаний

* Создание псевдонимов электронной почты.
* Настройка переадресации электронной почты.
* Знание наиболее распространенных программ MTA (postfix, sendmail, exim) (без настройки)

Неполный список используемых файлов, терминов и утилит

* `~/.forward`
* команды уровня эмуляции sendmail
* `newaliases`
* `mail`
* `mailq`
* `postfix`
* `sendmail`
* `exim`
