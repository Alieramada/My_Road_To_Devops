# Тема 3.4: Использование потоков, каналов и перенаправления

## Ключевые области знаний

* Перенаправление стандартного ввода, стандартного вывода и стандартной ошибки.
* Передача выходных данных одной команды на вход другой команды.
* Использовние выходных данных одной команды в качестве аргументов для другой команды.
* Отправка выходных данных как в стандартный вывод, так и в файл.

Неполный список используемых файлов, терминов и утилит

* `tee`
* `xargs`
