# 1.3. Изменение уровней запуска / целей загрузки и выключение или перезагрузка системы

## Ключевые области знаний

* Установка уровня выполнения или цели загрузки по умолчанию.
* Переключение между уровнями выполнения / целями загрузки, включая однопользовательский режим.
* Завершение работы и перезагрузка из командной строки.
* Предупреждение пользователей перед переключением целевых уровней выполнением / загрузки или другими важными системными событиями.
* Правильное завершение процессов.
* Осведомленность о acpid.

Неполный список используемых файлов, терминов и утилит

* `/etc/inittab`
* `shutdown`
* `init`
* `/etc/init.d/`
* `telinit`
* `systemd`
* `systemctl`
* `/etc/systemd/`
* `/usr/lib/systemd/`
* `wall`
