# 1.2 Загрузка системы

## Ключевые области знаний

* Предоставление загрузчику общих команд и параметров для ядра во время загрузки.
* Продемонстрировать знание последовательности загрузки от BIOS/UEFI до завершения загрузки.
* Понимание SysVinit и systemd.
* Осведомленность о выскочке.
* Проверьте события загрузки в файлах журнала.

## Неполный список используемых файлов, терминов и утилит

* `dmesg`
* `journalctl`
* BIOS
* UEFI
* загрузчик
* ядро
* `initramfs`
* `init`
* SysVinit
* systemd
