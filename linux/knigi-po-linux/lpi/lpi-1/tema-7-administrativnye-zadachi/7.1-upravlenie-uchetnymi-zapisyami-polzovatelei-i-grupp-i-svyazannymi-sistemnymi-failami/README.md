# 7.1 Управление учетными записями пользователей и групп и связанными системными файлами

## Ключевые области знаний

* Добавление, изменение и удаление пользователей и группы.
* Управление информацией о пользователях / группах в базах данных паролей / групп.
* Создание учетных записей специального назначения и с ограниченным доступом и управление ими.

## Неполный список используемых файлов, терминов и утилит

* `/etc/passwd`
* `/etc/shadow`
* `/etc/group`
* `/etc/skel/`
* `chage`
* `getent`
* `groupadd`
* `groupdel`
* `groupmod`
* `passwd`
* `useradd`
* `userdel`
* `usermod`
