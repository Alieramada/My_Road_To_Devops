# Урок 7.1.

## Введение <a href="#sec.107.1_01-in" id="sec.107.1_01-in"></a>

Управление пользователями и группами — очень важная часть работы любого системного администратора. В современных дистрибутивах Linux реализованы графические интерфейсы, которые позволяют быстро и легко управлять всеми действиями, связанными с этим ключевым аспектом. Эти интерфейсы отличаются друг от друга графическим оформлением, но функции у них одинаковые. С помощью этих инструментов вы можете просматривать, редактировать, добавлять и удалять локальных пользователей и группы. Однако для более продвинутого управления вам потребуется работать с командной строкой.

## Добавление учетных записей пользователей <a href="#adding_user_accounts" id="adding_user_accounts"></a>

В Linux вы можете добавить новую учётную запись пользователя с помощью команды `useradd` . Например, действуя с правами суперпользователя, вы можете создать новую учётную запись пользователя с именем `michael` со стандартными настройками, используя следующую команду:

```bash
# useradd michael
```

При выполнении команды `useradd` информация о пользователе и группе, хранящаяся в базах данных паролей и групп, обновляется для вновь созданной учётной записи пользователя, а также, если указано, создаётся домашний каталог нового пользователя. Также создаётся группа с тем же именем, что и у вновь созданной учётной записи пользователя.

После создания нового пользователя вы можете установить для него пароль с помощью команды `passwd` . Вы можете просмотреть его идентификатор пользователя (UID), идентификатор группы (GID) и группы, к которым он принадлежит, с помощью команд `id` и `groups` .

```bash
# passwd michael
Changing password for user michael.
New UNIX password:
Retype new UNIX password:
passwd: all authentication tokens updated successfully.
# id michael
uid=1000(michael) gid=100(michael) groups=100(michael)
# groups michael
michael : michael
```

{% hint style="info" %}
Помните, что любой пользователь может просмотреть свои UID, GID и группы, к которым он принадлежит, просто используя команды `id` и `groups` без аргументов, и что любой пользователь может изменить свой пароль с помощью команды `passwd` . Однако только пользователи с правами суперпользователя могут изменить пароль _любого_ пользователя.
{% endhint %}

Наиболее важными параметрами, которые применяются к команде `useradd` , являются:

`-c`

Создайте новую учётную запись пользователя с пользовательскими комментариями (например, с полным именем пользователя).

`-d`

Создайте новую учетную запись пользователя с пользовательским домашним каталогом.

`-e`

Создайте новую учётную запись пользователя, указав конкретную дату, когда она будет отключена.

`-f`

Создайте новую учётную запись пользователя, указав количество дней после истечения срока действия пароля, в течение которых пользователь должен обновить пароль (в противном случае учётная запись будет отключена).

`-g`

Создайте новую учетную запись пользователя с определенным GID.

`-G`

Создайте новую учетную запись пользователя, добавив ее в несколько дополнительных групп.

`-k`

Создайте новую учётную запись пользователя, скопировав файлы-шаблоны из определённого пользовательского каталога (эта опция действительна только в том случае, если указана опция `-m` или `--create-home`).

`-m`

Создайте новую учётную запись пользователя с домашним каталогом (если его нет).

`-M`

Создайте новую учетную запись пользователя без ее домашнего каталога.

`-s`

Создайте новую учетную запись пользователя с определенной оболочкой входа

`-u`

Создайте новую учетную запись пользователя с определенным UID.

Полный список опций приведен на страницах руководства по `useradd` команде.

## Изменение учетных записей пользователей <a href="#modifying_user_accounts" id="modifying_user_accounts"></a>

Иногда необходимо изменить атрибут существующей учётной записи пользователя, например имя для входа, оболочку для входа, дату истечения срока действия пароля и так далее. В таких случаях необходимо использовать команду `usermod`

```bash
# usermod -s /bin/tcsh michael
# usermod -c "Michael User Account" michael
```

Так же, как и в случае с `useradd` командой, для `usermod` команды требуются права root.

В приведенных выше примерах сначала изменяется оболочка входа в `michael`, а затем добавляется краткое описание этой учетной записи пользователя. Помните, что вы можете изменить несколько атрибутов одновременно, указав их одной командой.

Наиболее важными параметрами, которые применяются к команде `usermod` , являются:

`-c`

Добавьте краткий комментарий к указанной учетной записи пользователя.

`-d` Измените домашний каталог указанной учётной записи пользователя. При использовании с опцией&#x20;

`-m` содержимое текущего домашнего каталога перемещается в новый домашний каталог, который создаётся, если его ещё нет.

`-e`

Установите дату истечения срока действия указанной учетной записи пользователя.

`-f`

Задайте количество дней после истечения срока действия пароля, в течение которых пользователь должен обновить пароль (в противном случае учётная запись будет отключена).

`-g`

Измените основную группу указанной учетной записи пользователя (группа должна существовать).

`-G`

Добавьте дополнительные группы к указанной учётной записи пользователя. Каждая группа должна существовать и отделяться от следующей запятой без пробелов. При использовании отдельно эта опция удаляет все существующие группы, к которым принадлежит пользователь, а при использовании с опцией `-a` просто добавляет новые дополнительные группы к существующим.

`-l`

Измените имя для входа в указанную учетную запись пользователя.

`-L`

Заблокируйте указанную учётную запись пользователя. Это поставит восклицательный знак перед зашифрованным паролем в файле `/etc/shadow`, тем самым отключив доступ с паролем для этого пользователя.

`-s`

Измените оболочку входа в указанную учетную запись пользователя.

`-u`

Измените UID указанной учетной записи пользователя.

`-U`

Разблокируйте указанную учётную запись пользователя. Это уберёт восклицательный знак перед зашифрованным паролем в файле `/etc/shadow`

Полный список опций приведен на страницах руководства по `usermod` команде.

{% hint style="info" %}
Помните, что при изменении имени пользователя для входа в учётную запись вам, вероятно, следует переименовать домашний каталог этого пользователя и другие связанные с ним элементы, например файлы очереди отправки почты. Также помните, что при изменении идентификатора пользователя для входа в учётную запись вам, вероятно, следует изменить владельца файлов и каталогов за пределами домашнего каталога пользователя (идентификатор пользователя автоматически изменяется для почтового ящика пользователя и для всех файлов, принадлежащих пользователю и расположенных в его домашнем каталоге).
{% endhint %}

## Удаление учетных записей пользователей <a href="#deleting_user_accounts" id="deleting_user_accounts"></a>

Если вы хотите удалить учётную запись пользователя, вы можете использовать команду `userdel`. В частности, эта команда обновляет информацию, хранящуюся в базах данных учётных записей, удаляя все записи, относящиеся к указанному пользователю. Опция `-r` также удаляет домашний каталог пользователя и всё его содержимое, а также почтовый ящик пользователя. Другие файлы, расположенные в других местах, необходимо искать и удалять вручную.

```bash
# userdel -r michael
```

Что касается `useradd` и `usermod`, вам нужны права root для удаления учетных записей пользователей.

## Добавление, Изменение и Удаление Групп <a href="#adding_modifying_and_deleting_groups" id="adding_modifying_and_deleting_groups"></a>

Как и в случае с управлением пользователями, вы можете добавлять, изменять и удалять группы, используя команды `groupadd`, `groupmod` и `groupdel` с правами root. Если вы хотите создать новую группу с именем `developer`, вы можете выполнить следующую команду:

```bash
# groupadd -g 1090 developer
```

`-g`Опция этой команды создает группу с определенным GID.

{% hint style="info" %}
Помните, что при добавлении новой учётной записи пользователя основная и дополнительные группы, к которым она принадлежит, _должны_ существовать до запуска команды `useradd`.
{% endhint %}

Позже, если вы захотите переименовать группу с `developer` на `web-developer` и изменить её GID, вы можете выполнить следующие действия:

```bash
# groupmod -n web-developer -g 1050 developer
```

{% hint style="info" %}
Помните, что если вы меняете GID с помощью опции `-g`, вам следует изменить GID всех файлов и каталогов, которые должны оставаться в группе.
{% endhint %}

Наконец, если вы хотите удалить группу `web-developer`, вы можете выполнить следующие действия:

```bash
# groupdel web-developer
```

Вы не можете удалить группу, если она является основной группой учётной записи пользователя. Поэтому перед удалением группы необходимо удалить пользователя. Что касается пользователей, то при удалении группы файлы, принадлежащие этой группе, остаются в вашей файловой системе и не удаляются и не назначаются другой группе.

## Основной каталог

Когда вы добавляете новую учётную запись пользователя, даже если вы создаёте её домашний каталог, в только что созданный домашний каталог копируются файлы и папки из каталога-основы (по умолчанию `/etc/skel`). Идея проста: системный администратор хочет добавить новых пользователей с такими же файлами и папками в их домашней папке. Поэтому, если вы хотите изменить файлы и папки, которые автоматически создаются в домашнем каталоге новых учётных записей пользователей, вы должны добавить эти новые файлы и папки в каталог-основу.

{% hint style="info" %}
Обратите внимание, что если вы хотите вывести список всех файлов и каталогов в каталоге-скелете, вам нужно использовать команду `ls -al` .
{% endhint %}

## `/etc/login.defs`Файл <a href="#the_etclogin_defs_file" id="the_etclogin_defs_file"></a>

В Linux файл `/etc/login.defs` определяет параметры конфигурации, которые управляют созданием пользователей и групп. Кроме того, команды, описанные в предыдущих разделах, берут значения по умолчанию из этого файла.

Наиболее важными директивами являются:

`UID_MIN` и `UID_MAX`

Диапазон идентификаторов пользователей, которые могут быть назначены новым обычным пользователям.

`GID_MIN` и `GID_MAX`

Диапазон идентификаторов групп, которые могут быть присвоены новым обычным группам.

`CREATE_HOME`

Укажите, следует ли создавать домашний каталог по умолчанию для новых пользователей.

`USERGROUPS_ENAB`

Укажите, должна ли система по умолчанию создавать новую группу для каждой новой учётной записи пользователя с тем же именем, что и у пользователя, и должна ли она удалять основную группу пользователя при удалении учётной записи, если в ней больше нет участников.

`MAIL_DIR`

Каталог почтового спула.

`PASS_MAX_DAYS`

Максимальное количество дней, в течение которых может использоваться пароль.

`PASS_MIN_DAYS`

Минимальное количество дней, допустимое между сменами пароля.

`PASS_MIN_LEN`

Минимально допустимая длина пароля.

`PASS_WARN_AGE`

Количество дней предупреждения до истечения срока действия пароля.

{% hint style="info" %}
При управлении пользователями и группами всегда проверяйте этот файл, чтобы при необходимости просмотреть и изменить поведение системы по умолчанию.
{% endhint %}

## `passwd` Команда <a href="#the_passwd_command" id="the_passwd_command"></a>

Эта команда в основном используется для изменения пароля пользователя. Как описано ранее, любой пользователь может изменить свой собственный пароль, но только root может изменить пароль _любого_ пользователя. Это происходит потому, что `passwd` команда имеет установленный бит SUID (an `s` вместо флага исполняемого файла для владельца), что означает, что она выполняется с привилегиями владельца файла.

```
# ls -l /usr/bin/passwd
-rwsr-xr-x 1 root root 42096 mag 17 2015 /usr/bin/passwd
```

В зависимости от используемых параметров `passwd` вы можете управлять конкретными аспектами устаревания паролей:

`-d`

Удалите пароль учетной записи пользователя (таким образом, отключив пользователя).

`-e`

Принудительно измените пароль учетной записи пользователя.

`-i`

Задайте количество дней бездействия после истечения срока действия пароля, в течение которых пользователь должен обновить пароль (в противном случае учётная запись будет отключена).

`l`

Заблокируйте учётную запись пользователя (в файле `/etc/shadow` зашифрованный пароль начинается с восклицательного знака).

`-n`

Установите минимальное время действия пароля.

`-S`

Выводите информацию о состоянии пароля конкретной учетной записи пользователя.

`-u`

Разблокируйте учётную запись пользователя (восклицательный знак удаляется из поля пароля в файле `/etc/shadow`).

`-x`

Установите максимальное время действия пароля.

`-w`

Задайте количество дней до истечения срока действия пароля, в течение которых пользователь будет получать предупреждение о необходимости смены пароля.

{% hint style="info" %}
У групп также может быть пароль, который можно установить с помощью команды `gpasswd` . Пользователи, которые не являются членами группы, но знают её пароль, могут временно присоединиться к ней с помощью команды `newgrp` . Помните, что `gpasswd` также используется для добавления и удаления пользователей из группы, а также для установки списка администраторов и обычных участников группы.
{% endhint %}

## `chage` Команда <a href="#the_chage_command" id="the_chage_command"></a>

Эта команда, которая расшифровывается как «изменить возраст», используется для изменения информации о сроке действия пароля пользователя. Команда `chage` доступна только пользователю с правами root, за исключением опции `-l`, которую обычные пользователи могут использовать для просмотра информации о сроке действия пароля своей учётной записи.

Другими параметрами, которые применяются к `chage` команде, являются:

`-d`

Установите последнее изменение пароля для учетной записи пользователя.

`-E`

Установите дату истечения срока действия для учетной записи пользователя.

`-I`

Задайте количество дней бездействия после истечения срока действия пароля, в течение которых пользователь должен обновить пароль (в противном случае учётная запись будет отключена).

`-m`

Установите минимальный срок действия пароля для учетной записи пользователя.

`-M`

Установите максимальное время действия пароля для учетной записи пользователя.

`-W`

Задайте количество дней до истечения срока действия пароля, в течение которых пользователь будет получать предупреждение о необходимости смены пароля.

## Исследовательские упражнения

1. С помощью команды `groupadd` создайте группы `administrators` и `developers`. Предположим, что вы работаете от имени пользователя root.
2. Теперь, когда вы создали эти группы, выполните следующую команду: `useradd -G administrators,developers kevin`. Какие операции выполняет эта команда? Предположим, что `CREATE_HOME` и `USERGROUPS_ENAB` в `/etc/login.defs` установлены на `yes`.
3. Создайте новую группу с именем `designers`, переименуйте её в `web-designers` и добавьте эту новую группу во вторичные группы учётной записи `kevin` пользователя. Определите все группы, к которым принадлежит `kevin` и их идентификаторы.
4. Удалите только `developer` группу из второстепенных групп `kevin`.
5. Установите пароль для учетной записи пользователя `kevin`.
6. С помощью команды `chage` сначала проверьте срок действия учётной записи `kevin` пользователя, а затем измените его на 31 декабря 2022 года. Какую ещё команду можно использовать для изменения срока действия учётной записи пользователя?
7. Добавьте новую учётную запись пользователя с именем `emma` и UID 1050 и назначьте `administrators` основной группой, а `developers` и `web-designers` — дополнительными группами.
8. Измените оболочку входа из `emma` на `/bin/sh`.
9. Удалите  учетные записи пользователей `emma` и `kevin` и группы `administrators`, `developers` и `web-designers`.

* Как добавлять, изменять и удалять учетные записи пользователей.
* Как добавлять, изменять и удалять групповые учетные записи.
* Поддерживать базовый каталог.
* Отредактировать файл, управляющий созданием пользователей и групп.
* Изменить пароли учетных записей пользователей.
* Изменить информацию о старении паролей учетных записей пользователей.

В этом уроке обсуждались следующие файлы и команды:

`useradd`

Создать новую учетную запись пользователя.

`usermod`

Изменить учетную запись пользователя.

`userdel`

Удалить учетную запись пользователя.

`groupadd`

Создать новую учетную запись группы.

`groupmod`

Изменить учетную запись группы.

`groupdel`

Удалить учетную запись группы.

`passwd`

Изменить пароль учетных записей пользователей и контролируйте все аспекты старения пароля.

`chage`

Изменить информацию об истечении срока действия пароля пользователя.

`/etc/skel`

Расположение скелета каталога по умолчанию.

`/etc/login.defs`

Файл, который управляет созданием пользователей и групп и предоставляет значения по умолчанию для некоторых параметров учётных записей пользователей.

## Ответы на Упражнения с Руководством <a href="#sec.107.1_01-age" id="sec.107.1_01-age"></a>

1.  Для каждой из следующих команд определите соответствующую цель:

    | `usermod -L`  | Заблокировать учетную запись пользователя                                                                                  |
    | ------------- | -------------------------------------------------------------------------------------------------------------------------- |
    | `passwd -u`   | Разблокировать учетную запись пользователя                                                                                 |
    | `chage -E`    | Установить дату истечения срока действия учетной записи пользователя                                                       |
    | `groupdel`    | Удалить группу                                                                                                             |
    | `useradd -s`  | Создать новую учетную запись пользователя с определенной оболочкой входа                                                   |
    | `groupadd -g` | Создать новую группу с определенным GID                                                                                    |
    | `userdel -r`  | Удалить учётную запись пользователя и все файлы в его домашнем каталоге, сам домашний каталог и почтовый ящик пользователя |
    | `usermod -l`  | Изменить имя для входа в учетную запись пользователя                                                                       |
    | `groupmod -n` | Изменить название группы                                                                                                   |
    | `useradd -m`  | Создать новую учетную запись пользователя и ее домашний каталог                                                            |


2.  Для каждой из следующих `passwd` команд определите соответствующую `chage` команду:

    | `passwd -n` | `chage -m` |
    | ----------- | ---------- |
    | `passwd -x` | `chage -M` |
    | `passwd -w` | `chage -W` |
    | `passwd -i` | `chage -I` |
    | `passwd -S` | `chage -l` |


3.  Подробно объясните назначение команд, приведенных в предыдущем вопросе:

    В Linux вы можете использовать команду `passwd -n` (или `chage -m`) для установки минимального количества дней между сменами пароля, команду `passwd -x` (или `chage -M`) для установки максимального количества дней, в течение которых действителен пароль, команду `passwd -w` (или `chage -W`) для установки количества дней предупреждения до истечения срока действия пароля, команду `passwd -i` (или `chage -I`) для установки количества дней бездействия, в течение которых пользователь должен сменить пароль, и команду `passwd -S` (или `chage -l`) для отображения краткой информации о пароле учётной записи пользователя.
4.  Какие команды можно использовать для блокировки учётной записи пользователя? И какие команды для её разблокировки?

    Если вы хотите заблокировать учётную запись пользователя, вы можете использовать одну из следующих команд: `usermod -L`, `usermod --lock` и `passwd -l`. Если вы хотите разблокировать учётную запись, вы можете использовать `usermod -U`, `usermod --unlock` и `passwd -u`.

### Ответы на Исследовательские упражнения <a href="#sec.107.1_01-aee" id="sec.107.1_01-aee"></a>

1.  С помощью команды `groupadd` создайте группы `administrators` и `developers`. Предположим, что вы работаете от имени пользователя root.

    ```bash
    # groupadd administrators
    # groupadd developers
    ```
2.  Теперь, когда вы создали эти группы, выполните следующую команду: `useradd -G administrators,developers kevin`. Какие операции выполняет эта команда? Предположим, что `CREATE_HOME` и `USERGROUPS_ENAB` в `/etc/login.defs` установлены на `yes`.

    Команда добавляет нового пользователя с именем `kevin` в список пользователей системы, создаёт его домашний каталог (`CREATE_HOME` имеет значение yes, поэтому вы можете не указывать параметр -m) и создаёт новую группу с именем `kevin` в качестве основной группы для этой учётной записи (`USERGROUPS_ENAB` имеет значение yes). Наконец, файлы и папки, содержащиеся в каталоге-скелете, копируются в домашний каталог `kevin`.
3.  Создайте новую группу с именем `designers`, переименуйте её в `web-designers` и добавьте эту новую группу во вторичные группы учётной записи `kevin` пользователя. Определите все группы, к которым принадлежит `kevin` и их идентификаторы.

    ```bash
    # groupadd designers
    # groupmod -n web-designers designers
    # usermod -a -G web-designers kevin
    # id kevin
    uid=1010(kevin) gid=1030(kevin) groups=1030(kevin),1028(administrators),1029(developers),1031(web-designers)
    ```
4.  Удалите только `developers` группу из второстепенных групп `kevin`.

    ```bash
    # usermod -G administrators,web-designers kevin
    # id kevin
    uid=1010(kevin) gid=1030(kevin) groups=1030(kevin),1028(administrators),1031(web-designers)
    ```

    В команде `usermod` нет возможности удалить только одну группу, поэтому вам нужно указать все дополнительные группы, к которым принадлежит пользователь.
5.  Установите пароль для `kevin` учетной записи пользователя.

    ```bash
    # passwd kevin
    Changing password for user kevin.
    New UNIX password:
    Retype new UNIX password:
    passwd: all authentication tokens updated successfully.
    ```
6.  С помощью команды `chage` сначала проверьте срок действия учётной записи `kevin` пользователя, а затем измените его на 31 декабря 2022 года. Какую ещё команду можно использовать для изменения срока действия учётной записи пользователя?

    ```bash
    # chage -l kevin | grep "Account expires"
    Account expires		: never
    # chage -E 2022-12-31 kevin
    # chage -l kevin | grep "Account expires"
    Account expires		: dec 31, 2022
    ```

    `usermod`Команда с `-e` параметром эквивалентна `chage -E`.
7.  Добавьте новую учётную запись пользователя с именем `emma` и UID 1050 и назначьте `administrators` основной группой, а `developers` и `web-designers` — дополнительными группами.

    ```bash
    # useradd -u 1050 -g administrators -G developers,web-designers emma
    # id emma
    uid=1050(emma) gid=1028(administrators) groups=1028(administrators),1029(developers),1031(web-designers)
    ```
8.  Измените оболочку входа из `emma` на `/bin/sh`.

    ```bash
    # usermod -s /bin/sh emma
    ```
9.  Удалите `emma` и `kevin` учетные записи пользователей и группы `administrators`, `developers` и `web-designers`.

    ```bash
    # userdel -r emma
    # userdel -r kevin
    # groupdel administrators
    # groupdel developers
    # groupdel web-designers
    ```
