# 7.2 Автоматизация задач системного администрирования путем планирования заданий

## Ключевые области знаний

* Управление cron и at jobs.
* Настройка доступа пользователей к службам cron и at.
* Понимание юнитов systemd.

## Неполный список используемых файлов, терминов и утилит

* `/etc/cron.{d,daily,hourly,monthly,weekly}/`
* `/etc/at.deny`
* `/etc/at.allow`
* `/etc/crontab`
* `/etc/cron.allow`
* `/etc/cron.deny`
* `/var/spool/cron/`
* `crontab`
* `at`
* `atq`
* `atrm`
* `systemctl`
* `systemd-run`
