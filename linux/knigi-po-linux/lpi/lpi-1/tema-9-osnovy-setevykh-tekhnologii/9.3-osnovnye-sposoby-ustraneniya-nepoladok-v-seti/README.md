# 9.3 Основные способы устранения неполадок в сети

## Ключевые области знаний

* Настройка сетевых интерфейсов, включая просмотр и изменение конфигурации сетевых интерфейсов с помощью `iproute2`.
* Настройка маршрутизации, включая просмотр и изменение таблиц маршрутизации и установку маршрута по умолчанию с помощью `iproute2`.
* Отлаживание проблем, связанных с конфигурацией сети.
* Осведомленность о устаревших командах net-tools.

Неполный список используемых файлов, терминов и утилит

* `ip`
* `hostname`
* `ss`
* `ping`
* `ping6`
* `traceroute`
* `traceroute6`
* `tracepath`
* `tracepath6`
* `netcat`
* `ifconfig`
* `netstat`
* `route`
