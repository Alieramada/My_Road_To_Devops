# 9.4 Настройка DNS на стороне клиента

## Ключевые области знаний

* Запрос удаленных DNS-серверов.
* Настройка локального разрешения имен и использования удаленных DNS-серверов.
* Изменение порядка, в котором выполняется разрешение имен.
* Ошибки отладки, связанные с разрешением имен.
* `systemd-resolved`

## Неполный список используемых файлов, терминов и утилит

* `/etc/hosts`
* `/etc/resolv.conf`
* `/etc/nsswitch.conf`
* `host`
* `dig`
* `getent`
