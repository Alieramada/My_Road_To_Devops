# 9.2 Постоянная конфигурация сети

## Ключевые области знаний

* Понимание базовой конфигурации хоста TCP / IP
* Настройка конфигурации сетей ethernet и Wi-fi с помощью NetworkManager
* Осведомленность о systemd-networkd

Неполный список используемых файлов, терминов и утилит

* `/etc/hostname`
* `/etc/hosts`
* `/etc/nsswitch.conf`
* `/etc/resolv.conf`
* `nmcli`
* `hostnamectl`
* `ifup`
* `ifdown`
