# 2.2 Установка диспетчера загрузки

## Ключевые области знаний

* Предоставление альтернативных мест загрузки и вариантов загрузки из резервной копии.
* Установка и настрока загрузчика, такого как GRUB Legacy.
* Выполнение основных изменения конфигурации для GRUB 2.
* Взаимодействуйте с загрузчиком.

## Неполный список используемых файлов, терминов и утилит

* `menu.lst`, `grub.cfg` и `grub.conf`
* `grub-install`
* `grub-mkconfig`
* MBR
