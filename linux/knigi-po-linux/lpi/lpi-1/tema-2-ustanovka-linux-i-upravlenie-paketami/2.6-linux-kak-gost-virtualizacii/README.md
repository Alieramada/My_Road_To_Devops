# 2.6 Linux как гость виртуализации

## Ключевые области знаний

* Понять общую концепцию виртуальных машин и контейнеров
* Ознакомьтесь с общими элементами виртуальных машин в облаке IaaS, такими как вычислительные инстансы, блочные хранилища и сети
* Ознакомьтесь с уникальными свойствами системы Linux, которые необходимо изменить при клонировании системы или использовании её в качестве шаблона
* Узнайте, как системные образы используются для развертывания виртуальных машин, облачных инстансов и контейнеров
* Понимание расширений Linux, которые интегрируют Linux с продуктом виртуализации
* Осведомленность об облаке-init

## Неполный список используемых файлов, терминов и утилит

* Виртуальная машина
* Контейнер Linux
* Контейнер приложений
* Гостевые драйверы
* Ключи хоста SSH
* Идентификатор компьютера D-Bus
