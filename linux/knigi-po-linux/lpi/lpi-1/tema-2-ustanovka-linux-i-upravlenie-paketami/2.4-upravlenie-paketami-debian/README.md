# 2.4 Управление пакетами Debian

## Ключевые области знаний

* Устанавливка, обновление и удаление двоичных пакетов Debian.
* Поиск пакетов, содержащих определенные файлы или библиотеки, которые могут быть установлены.
* Получение информации о пакете, такой как версия, содержимое, зависимости, целостность пакета и статус установки (установлен пакет или нет).
* Осведомленность об apt.

## Неполный список используемых файлов, терминов и утилит

* `/etc/apt/sources.list`
* `dpkg`
* `dpkg-reconfigure`
* `apt-get`
* `apt-cache`
