# 2.5 RPM и YUM менеджер пакетов

## Ключевые области знаний

* Устанавливка, переустанавливка, обновление и удаление пакетов с помощью RPM, YUM и Zypper.
* Получение информации о пакетах RPM, такой как версия, состояние, зависимости, целостность и подписи.
* Определение, какие файлы предоставляет пакет, а также нахождение, из какого пакета взят конкретный файл.
* Осведомленность о dnf.

## Неполный список используемых файлов, терминов и утилит

* `rpm`
* `rpm2cpio`
* `/etc/yum.conf`
* `/etc/yum.repos.d/`
* `yum`
* `zypper`
