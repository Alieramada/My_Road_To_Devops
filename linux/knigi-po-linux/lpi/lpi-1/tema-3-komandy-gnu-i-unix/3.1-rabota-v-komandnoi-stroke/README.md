# 3.1 Работа в командной строке

## Ключевые области знаний

* Отдельные команды оболочки и последовательности команд в одну строку для выполнения базовых задач в командной строке.
* Использовние и модифицировние среды командной оболочки, включая определение переменных среды, ссылки на них и экспорт.
* Использование и редактирование истории команд.
* Вызов команды внутри и за пределами определенного пути.

Неполный список используемых файлов, терминов и утилит

* `bash`
* `echo`
* `env`
* `export`
* `pwd`
* `set`
* `unset`
* `type`
* `which`
* `man`
* `uname`
* `history`
* `.bash_history`
* Использование ковычек
