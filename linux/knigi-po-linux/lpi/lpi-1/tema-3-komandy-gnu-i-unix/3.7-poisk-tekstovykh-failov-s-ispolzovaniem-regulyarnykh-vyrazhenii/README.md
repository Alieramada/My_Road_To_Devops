# 3.7 Поиск текстовых файлов с использованием регулярных выражений

## Ключевые области знаний

* Создание простых регулярных выражений, содержащих несколько элементов обозначения.
* Понимание различия между базовыми и расширенными регулярными выражениями.
* Понятие специальных символов, классов символов, квантификаторов и якорей.
* Использовние инструментов регулярных выражений для выполнения поиска по файловой системе или содержимому файла.
* Использование регулярных выражений для удаления, изменения и замены текста.

## Неполный список используемых файлов, терминов и утилит

* `grep`
* `egrep`
* `fgrep`
* `sed`
* `regex(7)`
