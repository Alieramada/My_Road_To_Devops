## Как находить файлы <a href="#how_to_find_files" id="how_to_find_files"></a>

По мере использования компьютера количество и размер файлов постепенно увеличиваются. Иногда бывает сложно найти конкретный файл. К счастью, в Linux есть `find` для быстрого поиска и нахождения файлов. `find` используется следующий синтаксис:

```bash
find STARTING_PATH OPTIONS EXPRESSION
```

`STARTING_PATH`

определяет каталог, с которого начинается поиск.

`OPTIONS`

управляет поведением и добавляет определенные критерии для оптимизации процесса поиска.

`EXPRESSION`

определяет поисковый запрос.

```bash
$ find . -name "myfile.txt"
xt
```

Начальным путём в данном случае является текущий каталог. Опция `-name` указывает, что поиск выполняется по имени файла. `myfile.txt` — это имя файла для поиска. При использовании подстановочных знаков обязательно заключайте выражение в кавычки:

```bash
$ find /home/frank -name "*.png"
k/Pictures/logo.png
/home/frank/screenshot.png
```

Эта команда находит все файлы, заканчивающиеся на `.png` начиная с каталога `/home/frank/` и ниже. Если вы не понимаете, как использовать звёздочку (`*`), это описано в предыдущем уроке.

**Использование критериев для ускорения поиска**

Используйте `find` для поиска файлов по _типу_, _размеру_ или _времени_. Указывая один или несколько параметров, вы получите нужные результаты быстрее.

Переключается на поиск файлов по типу:

`-type f`

поиск файлов.

`-type d`

поиск по каталогу.

`-type l`

поиск по символическим ссылкам.

```bash
$ find . -type d -name "example"
```

Эта команда находит все каталоги в текущем каталоге и ниже, которые имеют имя `example`.

Другие критерии, которые можно было бы использовать с `find` , включают:

`-name`

выполняет поиск по заданному имени.

`-iname`

поиск по названию, однако регистр не имеет значения (например, тестовый пример `myFile` похож на `MYFILE`).

`-not`

возвращает те результаты, которые _не_ соответствуют тестовому варианту.

`-maxdepth N`

выполняет поиск по текущему каталогу, а также по подкаталогам  на`N`разных уровнях.

## **Поиск файлов по времени изменения**

`find` также позволяет фильтровать иерархию каталогов в зависимости от того, когда файл был изменен:

```bash
$ sudo find / -name "*.conf" -mtime 7
/etc/logrotate.conf
```

Эта команда будет искать все файлы во всей файловой системе (начальный путь — корневой каталог, т. е. `/`), которые заканчиваются символами `.conf` и были изменены за последние семь дней. Для доступа к каталогам, начиная с корневого каталога системы, этой команде потребуются повышенные права, отсюда и использование `sudo` здесь. Аргумент, передаваемый `mtime` представляет собой _количество дней_ с момента последнего изменения файла.

## **Поиск файлов по размеру**

`find` Вы также можете найти файлы по _размеру_. Например, поиск файлов размером более `2G` в `/var`:

```bash
$ sudo find /var -размер +2G
/var/lib/libvirt/images/debian10.qcow2
/var/lib/libvirt/images/rhel8.qcow2
```

Опция `-size` отображает файлы размером, соответствующим переданному аргументу. Вот несколько примеров аргументов:

`-size 100b`

файлы, размер которых составляет ровно 100 байт.

`-size +100k`

файлы размером более 100 килобайт.

`-size -20M`

файлы размером менее 20 мегабайт.

`-size +2G`

файлы размером более 2 гигабайт.

{% hint style="info" %}
Для поиска пустых файлов мы можем использовать: `find . -size 0b` или `find . -empty`.
{% endhint %}

## **Действие на основе набора результатов**

После завершения поиска можно выполнить действие с полученным набором данных с помощью `-exec`:

```bash
$ find . -name "*.conf" -exec chmod 644 '{}' \;
```

Это отфильтрует все объекты в текущем каталоге (`.`) и ниже по списку для файлов с именами, заканчивающимися на `.conf`, а затем выполнит команду `chmod 644` для изменения прав доступа к результатам.

Пока не беспокойтесь о значении `'{}' \;` — об этом мы поговорим позже.

## **Использование `grep` для фильтрации файлов на основе содержимого**

`grep` используется для поиска по вхождению ключевого слова.

Рассмотрим ситуацию, когда нам нужно найти файлы на основе содержимого:

```bash
$ find . -type f -exec grep "lpi" '{}' \; -print
./.bash_history
Alpine/M
helping/M
```

Это позволит найти все объекты в текущей иерархии каталогов (`.`), которые являются файлами (`-type f`), а затем выполнить команду `grep "lpi"` для каждого файла, удовлетворяющего условиям. Файлы, соответствующие этим условиям, будут выведены на экран (`-print`). Фигурные скобки (`{}`) являются заполнителем для результатов поиска `find`. `{}` заключены в одинарные кавычки (`'`), чтобы избежать передачи `grep` файлов с именами, содержащими специальные символы. Команда `-exec` завершается точкой с запятой (`;`), которую следует экранировать (`\;`), чтобы избежать интерпретации оболочкой.

Если добавить опцию `-delete` в конец выражения, будут удалены все совпадающие файлы. Эту опцию следует использовать, если вы уверены, что результаты соответствуют только тем файлам, которые вы хотите удалить.

В приведённом ниже примере `find` находит все файлы в иерархии, начиная с текущего каталога, а затем удаляет все файлы, которые заканчиваются символами `.bak`:

```bash
$ find . -name "*.bak" -delete
```

## Архивирование файлов <a href="#archiving_files" id="archiving_files"></a>

## **Команда `tar` (архивирование и сжатие)**

Команда `tar`, сокращенная от “архив на магнитной ленте tape archive(r)", используется для создания архивов tar путем преобразования группы файлов в архив. Архивы создаются для того, чтобы легко перемещать или создавать резервные копии группы файлов. Подумайте о `tar` как об инструменте, создающем клей, на который файлы можно прикреплять, группировать и легко перемещать.

`tar` Также есть возможность извлекать архивы tar, отображать список файлов, входящих в архив, и добавлять дополнительные файлы в существующий архив.

Синтаксис команды следующий:

```bash
tar [OPERATION_AND_OPTIONS] [ARCHIVE_NAME] [FILE_NAME(S)]
```

`OPERATION`

Допускается и требуется только один аргумент операции. Наиболее часто используемые операции:

`--create` (`-c`)

Создайте новый архив tar.

`--extract` (`-x`)

Извлеките весь архив или один или несколько файлов из архива.

`--list` (`-t`)

Отобразите список файлов, включенных в архив.

`OPTIONS`

Наиболее часто используемыми вариантами являются:

`--verbose` (`-v`)

Показать файлы, обрабатываемые командой `tar`.

`--file=archive-name` (`-f archive-name`)

Указывает имя файла архива.

`ARCHIVE_NAME`

Название архива.

`FILE_NAME(S)`

Список имён файлов для извлечения, разделённых пробелами. Если список не указан, извлекается весь архив.

## **Создание архива**

Допустим, у нас есть каталог с именем `stuff` в текущем каталоге, и мы хотим сохранить его в файл с именем `archive.tar`. Мы бы выполнили следующую команду:

```
$ tar -cvf archive.tar stuff
stuff/
stuff/service.conf
```

Вот что на самом деле означают эти переключатели:

`-c`

Создайте архив.

`-v`

Отображение хода выполнения в терминале при создании архива, также известное как «подробный» режим. В этих командах `-v` всегда является необязательным, но он полезен.

`-f`

Позволяет указать имя файла архива.

В целом, чтобы заархивировать один каталог или один файл в Linux, мы используем:

```bash
tar -cvf NAME-OF-ARCHIVE.tar /PATH/TO/DIRECTORY-OR-FILE
```

{% hint style="info" %}
`tar` работает рекурсивно. Он выполнит требуемое действие для каждого последующего каталога внутри указанного каталога.
{% endhint %}

Чтобы заархивировать несколько каталогов одновременно, перечислите все каталоги, разделяя их пробелами в разделе `/PATH/TO/DIRECTORY-OR-FILE`:

```bash
$ tar -cvf archive.tar stuff1 stuff2
```

Это привело бы к созданию архива `stuff1` и `stuff2` в `archive.tar`

## **Извлечение архива**

Мы можем извлечь архив с помощью `tar`:

```bash
$ tar -xvf archive.tar
stuff/
stuff/service.conf
```

При этом содержимое `archive.tar` будет извлечено в текущий каталог.

Эта команда аналогична команде создания архива, которая использовалась выше, за исключением переключателя `-x`, который заменяет переключатель `-c`.

Для извлечения содержимого архива в определенный каталог мы используем `-C`:

```bash
$ tar -xvf archive.tar -C /tmp
```

Это позволит извлечь содержимое `archive.tar` в `/tmp` каталог.

```bash
$ ls /tmp
stuff
```

## **Сжатие с помощью `tar`**

Команда GNU `tar`, включённая в дистрибутивы Linux, может создать архив `.tar` и затем сжать его с помощью `gzip` или `bzip2` сжатия за одну команду:

```bash
$ tar -czvf name-of-archive.tar.gz stuff
```

Эта команда создаст сжатый файл, используя `gzip` алгоритм (`-z`).

Хотя `gzip` сжатие чаще всего используется для создания `.tar.gz` или `.tgz` файлов, `tar` также поддерживается `bzip2` сжатие. Это позволяет создавать `bzip2` сжатые файлы, часто называемые `.tar.bz2`, `.tar.bz` или `.tbz` files.

Для этого мы заменим `-z` for `gzip` на `-j` for `bzip2`:

```bash
$ tar -cjvf name-of-archive.tar.bz stuff
```

Чтобы распаковать файл, мы заменяем `-c` на `-x`, где `x` означает «извлечь»:

```bash
$ tar -xzvf archive.tar.gz 
```

`gzip` работает быстрее, но обычно сжимается немного меньше, поэтому вы получаете файл несколько большего размера. `bzip2` работает медленнее, но сжимается немного больше, поэтому вы получаете файл несколько меньшего размера. В целом, однако, `gzip` и `bzip2` - это практически одно и то же, и оба будут работать аналогично.

В качестве альтернативы мы можем применить `gzip` или `bzip2` сжатие, используя команду `gzip` для `gzip` сжатия и команду `bzip` для `bzip` сжатия. Например, чтобы применить `gzip` сжатие, используйте:

```bash
gzip FILE-TO-COMPRESS
```

`gzip`

создает сжатый файл с тем же именем, но с `.gz` окончанием.

`gzip`

удаляет исходные файлы после создания сжатого файла.

Команда `bzip2` работает аналогичным образом.

Чтобы распаковать файлы, мы используем `gunzip` или `bunzip2` в зависимости от алгоритма сжатия.

## **Команда `cpio`**

`cpio` означает «вставить, скопировать». Используется для обработки архивных файлов, таких как `*.cpio` или `*.tar` файлы.

`cpio` выполняет следующие операции:

* Копирование файлов в архив.
* Извлечение файлов из архива.

Он принимает список файлов из стандартного ввода (в основном вывод из `ls`).

Для создания `cpio` архива мы используем:

```bash
$ ls | cpio -o > archive.cpio
```

Опция `-o` указывает `cpio` на создание выходного файла. В данном случае создаётся выходной файл `archive.cpio`. Команда `ls` перечисляет содержимое текущего каталога, которое необходимо заархивировать.

Для извлечения архива мы используем :

```bash
$ cpio -id < archive.cpio
```

Опция `-i` используется для выполнения извлечения. Опция `-d` создаст папку назначения. Символ `<` обозначает стандартный ввод. Входной файл для извлечения — `archive.cpio`.

## **Команда `dd`**

`dd` копирует данные из одного места в другое. Синтаксис командной строки `dd` отличается от синтаксиса многих других программ Unix, он использует синтаксис `option=value` для параметров командной строки, а не стандартные форматы `-option value` или `--option=value` GNU:

```bash
$ dd if=oldfile of=newfile
```

Эта команда скопирует содержимое `oldfile` в `newfile`, где `if=` — это входной файл, а `of=` — выходной.

{% hint style="info" %}
Команда `dd` обычно ничего не выводит на экран до тех пор, пока не завершится выполнение команды. При использовании опции `status=progress` консоль будет отображать объём работы, выполняемой командой. Например: `dd status=progress if=oldfile of=newfile`.
{% endhint %}

`dd` Также используется для преобразования данных в верхний/нижний регистр или для записи непосредственно в блоки, такие как `/dev/sdb`:

```bash
$ dd if=oldfile of=newfile conv=ucase
```

Это скопирует всё содержимое `oldfile` в `newfile` и сделает весь текст заглавными буквами.

Следующая команда создаст резервную копию всего жёсткого диска, расположенного по адресу `/dev/sda`, в файл с именем `backup.dd`:

```bash
$ dd if=/dev/sda of=backup.dd bs=4096
```

    *   С помощью `tar` укажите команду, которая создаст архив и сожмёт его с помощью `gzip`. Обратите внимание, что имя полученного файла должно заканчиваться на `.gz`:

        ```bash
        $ tar -zcvf db-first-quarter-2018.backup.tar.gz db-jan-2018.backup db-feb-2018.backup db-march-2018.backup db-apr-2018.backup
        ```
