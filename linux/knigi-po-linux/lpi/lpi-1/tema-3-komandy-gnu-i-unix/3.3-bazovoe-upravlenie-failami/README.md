# 3.3 Базовое управление файлами

## Ключевые области знаний

* Копирование, перемещение и удаление файлов и каталогов по отдельности.
* Рекурсивное копировние нескольких файлов и каталогов.
* Рекурсивное удаление файлов и каталогов.
* Поиск файлов и работа с ними в зависимости от типа, размера или времени создания.
* Использование tar, cpio и dd.

## Неполный список используемых файлов, терминов и утилит

* `cp`
* `find`
* `mkdir`
* `mv`
* `ls`
* `rm`
* `rmdir`
* `touch`
* `tar`
* `cpio`
* `dd`
* `file`
* `gzip`
* `gunzip`
* `bzip2`
* `bunzip2`
* globbing файлов
