# Урок 3.3.1.

## Введение <a href="#sec.103.3_01-in" id="sec.103.3_01-in"></a>

В Linux всё является файлом, поэтому очень важно знать, как с ними работать. В этом уроке мы рассмотрим основные операции с файлами.

В целом, как пользователю Linux, вам придётся перемещаться по файловой системе, копировать файлы из одного места в другое и удалять файлы. Мы также рассмотрим команды, связанные с управлением файлами.

Файл — это объект, в котором хранятся данные и программы. Он состоит из содержимого и метаданных (размер файла, владелец, дата создания, разрешения). Файлы организованы в каталоги. Каталог — это файл, в котором хранятся другие файлы.

Различные типы файлов включают:

Обычные файлы

в которых хранятся данные и программы.

Каталоги

которые содержат другие файлы.

Специальные файлы

которые используются для ввода и вывода.

Конечно, существуют и другие типы файлов, но они выходят за рамки этого урока. Позже мы обсудим, как определять эти различные типы файлов.

## Манипулирование файлами <a href="#sec.103.3_01-mf" id="sec.103.3_01-mf"></a>

## **Использование `ls` для составления списка файлов**

Команда `ls` — один из важнейших инструментов командной строки, который вам следует изучить для навигации по файловой системе.

В своей базовой форме, `ls` будут перечислены _только_ имена файлов и каталогов:

```bash
$ ls
Desktop Downloads   emp_salary  file1   Music   Public  Videos
Documents   emp_name    examples.desktop    file2   Pictures    Templates
```

При использовании с `-l` в формате «длинного списка» отображаются права доступа к файлу или каталогу, владелец, размер, дата изменения, время и имя:

```bash
$ ls -l
total 60
drwxr-xr-x  2   frank   frank   4096    Apr 1   2018    Desktop
drwxr-xr-x  2   frank   frank   4096    Apr 1   2018    Documents
drwxr-xr-x  2   frank   frank   4096    Apr 1   2018    Downloads
-rw-r--r--  1   frank   frank     21    Sep 7   12:59   emp_name
-rw-r--r--  1   frank   frank     20    Sep 7   13:03   emp_salary
-rw-r--r--  1   frank   frank   8980    Apr 1   2018    examples.desktop
-rw-r--r--  1   frank   frank     10    Sep 1   2018    file1
-rw-r--r--  1   frank   frank     10    Sep 1   2018    file2
drwxr-xr-x  2   frank   frank   4096    Apr 1   2018    Music
drwxr-xr-x  2   frank   frank   4096    Apr 1   2018    Pictures
drwxr-xr-x  2   frank   frank   4096    Apr 1   2018    Public
drwxr-xr-x  2   frank   frank   4096    Apr 1   2018    Templates
drwxr-xr-x  2   frank   frank   4096    Apr 1   2018    Videos
```

Первый символ в выходных данных указывает на тип файла:

`-`

для обычного файла.

`d`

для каталога.

`c`

для специального файла.

Чтобы отобразить размеры файлов в удобочитаемом формате, добавьте опцию `-h`:

```bash
$ ls -lh
total 60K
drwxr-xr-x  2   frank   frank   4.0K    Apr 1   2018    Desktop
drwxr-xr-x  2   frank   frank   4.0K    Apr 1   2018    Documents
drwxr-xr-x  2   frank   frank   4.0K    Apr 1   2018    Downloads
-rw-r--r--  1   frank   frank     21    Sep 7   12:59   emp_name
-rw-r--r--  1   frank   frank     20    Sep 7   13:03   emp_salary
-rw-r--r--  1   frank   frank   8.8K    Apr 1   2018    examples.desktop
-rw-r--r--  1   frank   frank     10    Sep 1   2018    file1
-rw-r--r--  1   frank   frank     10    Sep 1   2018    file2
drwxr-xr-x  2   frank   frank   4.0K    Apr 1   2018    Music
drwxr-xr-x  2   frank   frank   4.0K    Apr 1   2018    Pictures
drwxr-xr-x  2   frank   frank   4.0K    Apr 1   2018    Public
drwxr-xr-x  2   frank   frank   4.0K    Apr 1   2018    Templates
drwxr-xr-x  2   frank   frank   4.0K    Apr 1   2018    Videos
```

Чтобы вывести список всех файлов, включая скрытые (те, которые начинаются с `.`), используйте опцию `-a`:

```bash
$ ls -a
.               .dbus   file1   .profile
..              Desktop file2   Public
.bash_history   .dmrc  .gconf  .sudo_as_admin_successful
```

Файлы конфигурации, такие как `.bash_history` которые по умолчанию скрыты, теперь видны.

В общем случае, `ls` синтаксис команды задается:

```bash
ls OPTIONS FILE
```

Где `OPTIONS` — это любой из показанных ранее вариантов (чтобы просмотреть все возможные варианты, выполните `man ls`), а `FILE` — это имя файла или каталога, сведения о котором вы хотите вывести.

{% hint style="info" %}
Если значение `FILE` не указано, подразумевается текущий каталог.
{% endhint %}

## **Создание, копирование, перемещение и удаление файлов**

## **Создание файлов с помощью `touch`**

Команда `touch` — это самый простой способ создать новые пустые файлы. Вы также можете использовать её для изменения временных меток (т. е. времени изменения) существующих файлов и каталогов. Синтаксис использования `touch`:

```bash
touch OPTIONS FILE_NAME(S)
```

Без каких-либо параметров `touch` создаст новые файлы для любых имён файлов, указанных в качестве аргументов, при условии, что файлы с такими именами ещё не существуют. `touch` может создавать любое количество файлов одновременно:

```bash
$ touch file1 file2 file3
```

В результате будут созданы три новых пустых файла с именами `file1`, `file2` и `file3`.

Несколько опций `touch` специально разработаны для того, чтобы пользователь мог изменять временные метки для файлов. Например, опция `-a` изменяет только время доступа, а опция `-m` изменяет только время изменения. При совместном использовании обеих опций время доступа и время изменения изменяются на текущее время:

```bash
$ touch -am file3
```

## **Копирование файлов с помощью `cp`**

Как пользователь Linux, вы часто будете копировать файлы из одного места в другое. Будь то перемещение музыкального файла из одного каталога в другой или системного файла, используйте `cp` для всех задач по копированию:

```bash
$ cp file1 dir2
```

Эта команда может быть буквально интерпретирована как копирование `file1` в каталог `dir2`. В результате `file1` будет находиться внутри `dir2`. Чтобы эта команда успешно выполнилась, `file1` должен существовать в текущем каталоге пользователя. В противном случае система выдаст сообщение об ошибке `No such file or directory`.

```
$ cp dir1/file1 dir2
```

В этом случае обратите внимание, что путь к `file1` более очевиден. Исходный путь может быть выражен как _относительный_ или _абсолютный путь_. Относительные пути указываются относительно конкретного каталога, а абсолютные пути не указываются относительно чего-либо. Ниже мы подробнее разъясним это понятие.

На данный момент просто обратите внимание, что эта команда копирует `file1` в каталог `dir2`. Путь к `file1` указан более подробно, поскольку пользователь в данный момент находится не в `dir1`.

```bash
$ cp /home/frank/Documents/file2 /home/frank/Documents/Backup
```

В этом третьем случае `file2` находится по адресу `/home/frank/Documents` и копируется в каталог `/home/frank/Documents/Backup`. Приведённый здесь путь к источнику является _абсолютным_. В двух приведённых выше примерах пути к источникам являются _относительными_. Если путь начинается с символа `/`, то это абсолютный путь, в противном случае — относительный.

Общий синтаксис для `cp` таков:

```bash
cp OPTIONS SOURCE DESTINATION
```

`SOURCE` это файл для копирования, а `DESTINATION` — каталог, в который будет скопирован файл. `SOURCE` и `DESTINATION` могут быть указаны как абсолютные или относительные пути.

## **Перемещение файлов с помощью `mv`**

Как и `cp` для копирования, Linux предоставляет команду для перемещения и переименования файлов. Она называется `mv`.

Операция перемещения аналогична операции вырезания и вставки, которую вы обычно выполняете с помощью графического пользовательского интерфейса (GUI).

Если вы хотите переместить файл в новое место, используйте `mv` следующим образом:

```bash
mv FILENAME DESTINATION_DIRECTORY
```

Вот пример:

```bash
$ mv myfile.txt /home/frank/Documents
```

Результатом является то, что `myfile.txt` перемещается в пункт назначения `/home/frank/Documents`.

Чтобы переименовать файл, `mv` используется следующим образом:

```bash
$ mv old_file_name new_file_name
```

При этом имя файла изменяется с `old_file_name` на `new_file_name`.

По умолчанию `mv` не будет запрашивать у вас подтверждение (технически это называется «не будет выдавать запрос»), если вы хотите перезаписать (переименовать) существующий файл. Однако вы можете разрешить системе выдавать запрос, используя опцию `-i`:

```bash
$ mv -i old_file_name new_file_name
mv: overwrite 'new_file_name'?
```

Эта команда запросит разрешение пользователя перед перезаписью `old_file_name` на `new_file_name`.

И наоборот, используя `-f`:

```bash
$ mv -f old_file_name new_file_name
```

принудительно перезаписал бы файл, не спрашивая никакого разрешения.

## **Удаление файлов с помощью `rm`**

**Удаление файлов с помощью `rm`**

`rm` используется для удаления файлов. Представьте, что это сокращённая форма слова «удалить». Обратите внимание, что удаление файла обычно необратимо, поэтому эту команду следует использовать с осторожностью.

```bash
$ rm file1
```

Эта команда приведет к удалению `file1`.

```bash
$ rm -i file1
rm: remove regular file 'file1'?
```

Эта команда запросит у пользователя подтверждение перед удалением `file1`. Помните, что при использовании `-i` выше мы видели опцию `mv`.

```bash
$ rm -f file1
```

Эта команда удаляет данные принудительно, `file1` не запрашивая вашего подтверждения.

Одновременно можно удалить несколько файлов:

```bash
$ rm file1 file2 file3
```

В этом примере `file1`, `file2` и `file3` удаляются одновременно.

Синтаксис для `rm` обычно задается:

```bash
rm OPTIONS FILE
```

## Создание и удаление каталогов <a href="#creating_and_deleting_directories" id="creating_and_deleting_directories"></a>

## **Создание каталогов с помощью `mkdir`**

Создание каталогов имеет решающее значение для организации ваших файлов и папок. Файлы можно логически сгруппировать, поместив их в каталог. Чтобы создать каталог, используйте `mkdir`:

```
mkdir OPTIONS DIRECTORY_NAME
```

где `DIRECTORY_NAME` — имя создаваемого каталога. Одновременно можно создать любое количество каталогов:

```bash
$ mkdir dir1
```

создаст каталог `dir1` в текущем каталоге пользователя.

```bash
$ mkdir dir1 dir2 dir3
```

Предыдущая команда создала бы три каталога `dir1`, `dir2` и `dir3` одновременно.

Чтобы создать каталог вместе с его подкаталогами, используйте опцию `-p` («родители»):

```bash
$ mkdir -p parents/children
```

Эта команда создаст структуру каталогов `parents/children`, то есть создаст каталоги `parents` и `children`. `children` будут находиться внутри `parents`.

**Удаление каталогов с помощью `rmdir`**

`rmdir` удаляет каталог, _если он пуст_. Его синтаксис:

```bash
rmdir OPTIONS DIRECTORY
```

где `DIRECTORY` может быть один аргумент или список аргументов.

```bash
$ rmdir dir1
```

Эта команда приведет к удалению `dir1`.

```bash
$ rmdir dir1 dir2
```

Эта команда одновременно удалит `dir1` и `dir2`.

Вы можете удалить каталог вместе с его подкаталогом:

```bash
$ rmdir -p parents/children
```

Это приведёт к удалению структуры каталогов `parents/children`. Обратите внимание, что если какие-либо каталоги не пусты, они не будут удалены.

## Рекурсивное манипулирование файлами и каталогами <a href="#sec.103.3_01-rmfd" id="sec.103.3_01-rmfd"></a>

Чтобы управлять каталогом и его содержимым, необходимо применить _рекурсию_. Рекурсия означает выполнение действия и его повторение по всему дереву каталогов. В Linux с рекурсией обычно связаны параметры `-r` или `-R` или `--recursive`.

Следующий сценарий поможет вам лучше понять рекурсию:

Вы перечисляете содержимое каталога `students`, который содержит два подкаталога `level1` и `level2` и файл с именем `frank`. Применив рекурсию, команда `ls` перечислит содержимое `students` т.е. `level1`, `level2` и `frank`, но не остановится на этом. Она также перейдёт в подкаталоги `level1` и `level2` и перечислит их содержимое и так далее вниз по дереву каталогов.

## **Рекурсивный список с `ls -R`**

`ls -R` Используется для вывода списка содержимого каталога вместе с его подкаталогами и файлами.

```bash
$ ls -R mydirectory
mydirectory/:
file1   newdirectory

mydirectory/newdirectory:
```

В приведённом выше списке перечислены `mydirectory` и всё их содержимое. Вы можете заметить, что `mydirectory` содержит подкаталог `newdirectory` и файл `file1`. `newdirectory` пуст, поэтому содержимое не отображается.

В общем случае, чтобы вывести список содержимого каталога, включая его подкаталоги, используйте:

```bash
ls -R DIRECTORY_NAME
```

Добавление завершающей косой черты к `DIRECTORY_NAME` не имеет никакого эффекта:

```bash
$ ls -R animal
```

тоже самое что и

```bash
$ ls -R animal/
```

## **Рекурсивное копирование с `cp -r`**

`cp -r` (или `-R` или `--recursive`) позволяет скопировать каталог вместе со всеми его подкаталогами и файлами.

```bash
$ tree mydir
mydir
|_file1
|_newdir
    |_file2
    |_insidenew
        |_lastdir


3 directories, 2 files
$ mkdir newcopy
$ cp mydir newcopy
cp: omitting directory 'mydir'
$ cp -r mydir newcopy
* tree newcopy
newcopy
|_mydir
    |_file1
    |_newdir
        |_file2
        |_insidenew
            |_lastdir

4 directories, 2 files
```

В приведенном выше списке мы видим, что при попытке копирования `mydir` в `newcopy`, используя `cp` без `-r`, система отображает сообщение `cp: omitting directory 'mydir'`. Однако при добавлении опции `-r` все содержимое `mydir`, включая само себя, копируется в `newcopy`.

Для копирования каталогов и подкаталогов используйте:

```bash
cp -r SOURCE DESTINATION
```

## **Рекурсивное Удаление с помощью `rm -r`**

`rm -r` удалит каталог и все его содержимое (подкаталоги и файлы).

{% hint style="info" %}
Будьте очень осторожны при использовании `-r` или комбинации параметров `-rf` с командой `rm`. Рекурсивное удаление важного системного каталога может привести к неработоспособности системы. Используйте команду рекурсивного удаления только в том случае, если вы абсолютно уверены, что содержимое каталога можно безопасно удалить с компьютера.
{% endhint %}

При попытке удалить каталог без использования `-r` система выдаст сообщение об ошибке:

```bash
$ rm newcopy/
rm: cannot remove 'newcopy/': Is a directory
$ rm -r newcopy/
```

Чтобы удаление вступило в силу, нужно добавить `-r` как во второй команде.

{% hint style="info" %}
Вам может быть интересно, почему мы не используем `rmdir` в этом случае. Между этими двумя командами есть небольшая разница. `rmdir` удалит файл только в том случае, если указанный каталог пуст, в то время как `rm -r` можно использовать независимо от того, пуст каталог или нет.
{% endhint %}

Добавьте опцию `-i` запрашивать подтверждение перед удалением файла:

```bash
$ rm -ri mydir/
rm: remove directory 'mydir/'?
```

#### Globbing файлов и подстановочные знаки <a href="#file_globbing_and_wildcards" id="file_globbing_and_wildcards"></a>

Globbing файлов — это функция, предоставляемая оболочкой Unix/Linux для представления нескольких имён файлов с помощью специальных символов, называемых _подстановочными знаками_. Подстановочные знаки — это, по сути, символы, которые могут использоваться для замены одного или нескольких символов. Они позволяют, например, отобразить все файлы, которые начинаются с буквы `A` или все файлы, которые заканчиваются буквами `.conf`.

Подстановочные знаки очень полезны, поскольку их можно использовать с такими командами, как `cp`, `ls` или `rm`.

Ниже приведены некоторые примеры масштабирования файлов:

`rm *`

Удалите все файлы в текущем рабочем каталоге.

`ls l?st`

Выведите список всех файлов, имена которых начинаются с `l` и содержат один символ, а заканчиваются на `st`.

`rmdir [a-z]*`

Удалите все каталоги, название которых начинается с буквы.

#### Типы подстановочных знаков <a href="#types_of_wildcards" id="types_of_wildcards"></a>

Есть три символа, которые можно использовать в качестве подстановочных знаков в Linux:

`*` (звездочка)

который представляет ноль, одно или несколько вхождений любого символа.

`?` (вопросительный знак)

который представляет собой единичное вхождение любого символа.

`[ ]` (символы в квадратных скобках)

обозначает любое вхождение символа (символов), заключённого в квадратные скобки. Можно использовать различные типы символов: цифры, буквы, другие специальные символы. Например, выражение `[0-9]` соответствует всем цифрам.

## **Звездочка**

Звездочка (`*`) соответствует нулю, одному или нескольким вхождениям любого символа.

Например:

```bash
$ find /home -name *.png
```

Это позволит найти все файлы, которые заканчиваются на `.png`: `photo.png`, `cat.png`, `frank.png`. Команда `find` будет рассмотрена подробнее в следующем уроке.

Аналогично:

```bash
$ ls lpic-*.txt
```

будут перечислены все текстовые файлы, которые начинаются с символов `lpic-` за которыми следует любое количество символов и которые заканчиваются символами `.txt`, например `lpic-1.txt` и `lpic-2.txt`.

Подстановочный знак «звездочка» можно использовать для управления (копирования, удаления или перемещения) всем содержимым каталога:

```bash
$ cp -r animal/* forest
```

В этом примере все содержимое `animal` копируется в `forest`.

В общем случае для копирования всего содержимого каталога мы используем:

```bash
cp -r SOURCE_PATH/* DEST_PATH
```

где `SOURCE_PATH` можно опустить, если мы уже находимся в нужном каталоге.

Звёздочку, как и любой другой символ подстановки, можно использовать многократно в одной команде и в любом месте:

```bash
$ rm *ate* 
```

Имена файлов, начинающиеся с нуля, одного или нескольких вхождений любого символа, за которыми следуют буквы `ate` и которые заканчиваются нулём, одним или несколькими вхождениями любого символа, будут удалены.

## **Вопросительный знак**

Вопросительный знак (`?`) соответствует _единственному_ вхождению символа.

Рассмотрим список:

```bash
$ ls
last.txt lest.txt list.txt third.txt past.txt
```

Чтобы вернуть только файлы, которые начинаются с `l` и за которыми следует любой одиночный символ и символы `st.txt`, мы используем подстановочный знак (`?`):

```bash
$ ls l?st.txt
last.txt lest.txt list.txt
```

Отображаются только файлы `last.txt`, `lest.txt` и `list.txt`, поскольку они соответствуют заданным критериям.

Аналогично,

```bash
$ ls ??st.txt
last.txt lest.txt list.txt past.txt
```

выходные файлы, которым предшествуют любые два символа, за которыми следует текст `st.txt`.

## **Символы, заключенные в квадратные скобки**

Подстановочные знаки в квадратных скобках соответствуют любому вхождению символа (символов), заключённого в квадратные скобки:

```bash
$ ls l[aef]st.txt
last.txt lest.txt
```

Эта команда выведет список всех файлов, начинающихся с `l` и содержащих _любой_ из символов набора `aef` и заканчивающихся на `st.txt`.

В квадратные скобки также могут быть заключены диапазоны:

```bash
$ ls l[a-z]st.txt
last.txt lest.txt list.txt
```

Выводит все файлы с именами, начинающимися с `l` и содержащими любую строчную букву в диапазоне `a`-`z` и заканчивающимися на `st.txt`.

В квадратных скобках также можно указать несколько диапазонов:

```bash
$ ls
student-1A.txt student-2A.txt student-3.txt
$ ls student-[0-9][A-Z].txt
student-1A.txt student-2A.txt
```

В списке представлен школьный каталог со списком зарегистрированных учащихся. Чтобы отобразить только тех учащихся, чьи регистрационные номера соответствуют следующим критериям:

* начните с `student-`
* за ним следует цифра и символ в верхнем регистре
* и заканчивается словами `.txt`

## **Комбинирование подстановочных знаков**

Подстановочные знаки можно комбинировать, как в:

```bash
$ ls
last.txt lest.txt list.txt third.txt past.txt
$ ls [plf]?st* 
last.txt lest.txt list.txt past.txt
```

Первый компонент подстановочного знака (`[plf]`) соответствует любому из символов `p`, `l` или `f`. Второй компонент подстановочного знака (`?`) соответствует любому отдельному символу. Третий компонент подстановочного знака (`*`) соответствует нулю, одному или нескольким вхождениям любого символа.

```bash
$ ls
file1.txt file.txt file23.txt fom23.txt
$ ls f*[0-9].txt
file1.txt file23.txt fom23.txt
```

Предыдущая команда выводит все файлы, которые начинаются с буквы `f`, за которой следует любой набор букв, по крайней мере одна цифра и заканчивается на `.txt`. Обратите внимание, что `file.txt` не выводится, так как не соответствует этим критериям.

### Краткие сведения <a href="#sec.103.3_01-su" id="sec.103.3_01-su"></a>

В этом уроке мы узнали, как просматривать содержимое каталога с помощью команды `ls`, как копировать (`cp`) файлы и папки, а также перемещать (`mv`) их. Мы также рассмотрели, как создавать новые каталоги с помощью команды `mkdir`. Также были рассмотрены команды для удаления файлов (`rm`) и папок (`rmdir`).

В этом уроке вы также узнали о подстановке имён файлов и подстановочных знаках. Подстановка имён файлов используется для представления нескольких имён файлов с помощью специальных символов, называемых подстановочными знаками. Основные подстановочные знаки и их значения:

`?` (вопросительный знак)

представляет собой единственное вхождение символа.

`[ ]` (квадратные скобки)

представляет любое вхождение символа (ов), заключенного в квадратные скобки.

`*` (звездочка)

представляет ноль, одно или несколько вхождений любого символа.

Вы можете объединить любые из этих подстановочных знаков в одном операторе.
