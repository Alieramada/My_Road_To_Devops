# Урок 3.8 Базовое редактирование файлов

## Ключевые области знаний

* Перемещение по документу с помощью vi.
* Понимание и использовать режимов vi.
* Вставка, редактирование, удаление, копирование и поиск текста в vi.
* Знакомство с Emacs, nano и vim.
* Настройка стандартного редактора.

Неполный список используемых файлов, терминов и утилит

* `vi`
* `/`, `?`
* `h`, `j`, `k`, `l`
* `i`, `o`, `a`
* `d`, `p`, `y`, `dd`, `yy`
* `ZZ`, `:w!`, `:q!`
* `EDITOR`
