# 3.6 Изменение приоритета выполнения процесса

## Ключевые области знаний

* Узнать приоритет по умолчанию для создаваемого задания.
* Запустить программу с более высоким или более низким приоритетом, чем по умолчанию.
* Изменить приоритет запущенного процесса.

## Неполный список используемых файлов, терминов и утилит

* `nice`
* `ps`
* `renice`
* `top`
