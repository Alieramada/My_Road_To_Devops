# 3.5 Создание, отслеживание и завершение процессов

## Ключевые области знаний

* Выполнение задания на переднем плане и в фоновом режиме.
* Отправка сигнала программе о продолжении работы после выхода из системы.
* Мониторинг активных процессов.
* Выбор и сортировка процессов для отображения.
* Отправка сигналов процессам.
