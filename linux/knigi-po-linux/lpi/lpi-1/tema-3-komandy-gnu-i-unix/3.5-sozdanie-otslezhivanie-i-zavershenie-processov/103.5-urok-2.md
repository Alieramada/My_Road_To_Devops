# 103.5 Урок 2

## Введение <a href="#sec.103.5_02-in" id="sec.103.5_02-in"></a>

Инструменты и утилиты, о которых мы говорили в предыдущем уроке, очень полезны для мониторинга процессов в целом. Однако системному администратору может потребоваться сделать ещё один шаг. В этом уроке мы обсудим концепцию мультиплексоров терминалов и узнаем о _GNU Screen_ и _tmux_, поскольку, несмотря на современные и отличные эмуляторы терминалов, мультиплексоры по-прежнему обладают некоторыми полезными и мощными функциями для продуктивной работы системного администратора.

#### Особенности терминальных мультиплексоров <a href="#features_of_terminal_multiplexers" id="features_of_terminal_multiplexers"></a>

В электронике мультиплексор (или _mux_) — это устройство, которое позволяет подключать несколько входов к одному выходу. Таким образом, терминальный мультиплексор даёт нам возможность переключаться между различными входами по мере необходимости. Несмотря на то, что `screen` и `tmux` не являются полностью идентичными, у них есть ряд общих черт:

* Любой успешный вызов приведёт как минимум к сеансу, который, в свою очередь, будет включать как минимум окно. Окна содержат программы.
* Окна можно разделить на области или панели, что может повысить производительность при одновременной работе с различными программами.
* Простота управления: для выполнения большинства команд используется комбинация клавиш — так называемый _префикс команды_ или _клавиша команды_ — за которой следует другой символ.
* Сессии могут быть отделены от текущего терминала (то есть программы отправляются в фоновый режим и продолжают работать). Это гарантирует полное выполнение программ, даже если мы случайно закроем терминал, столкнёмся с зависанием терминала или даже потерей удалённого подключения.
* Подключение к сокетам.
* Режим копирования.
* Они легко настраиваются.

## Экран GNU <a href="#gnu_screen" id="gnu_screen"></a>

В первые годы существования Unix (1970-е — 1980-е) компьютеры в основном состояли из терминалов, подключённых к центральному компьютеру. Вот и всё, никаких нескольких окон или вкладок. Именно это стало причиной создания GNU Screen в 1987 году: эмуляция нескольких независимых _экранов VT100_ на одном физическом терминале.

## Окна

GNU Screen запускается простым вводом `screen` в терминале. Сначала вы увидите приветственное сообщение:\


```bash
GNU Screen version 4.05.00 (GNU) 10-Dec-16

Copyright (c) 2010 Juergen Weigert, Sadrul Habib Chowdhury
Copyright (c) 2008, 2009 Juergen Weigert, Michael Schroeder, Micah Cowan, Sadrul Habib Chowdhury
Copyright (c) 1993-2002, 2003, 2005, 2006, 2007 Juergen Weigert, Michael Schroeder
Copyright (c) 1987 Oliver Laumann
(...)
```

Нажмите пробел или Enter, чтобы закрыть сообщение, и вы увидите командную строку:

```bash
$
```

Может показаться, что ничего не произошло, но дело в том, что `screen` уже создал и управляет своим первым сеансом и окном. Префикс команды Screen — Ctrl+a. Чтобы увидеть все окна в нижней части экрана терминала, введите Ctrl+a-w:

```
0* $ bash
```

Вот оно, наше единственное на данный момент окно! Обратите внимание, что отсчет начинается с 0. Чтобы создать другое окно, введите Ctrl+a-c. Вы увидите новую строку. Давайте начнем `ps` в этом новом окне:

```bash
$ ps
 PID TTY ВРЕМЯ CMD
 974 pts/2 00:00:00 bash
 981 pts/2 00:00:00 ps
```

Вот у нас есть два окна (обратите внимание на звёздочку, обозначающую то, которое отображается в данный момент). Однако, поскольку они были запущены с помощью Bash, они оба имеют одно и то же имя. Поскольку мы вызвали `ps` в текущем окне, давайте переименуем его в то же имя. Для этого нужно ввести Ctrl+a-A и ввести новое имя окна (`ps`) при появлении запроса:

```bash
Set window's title to: ps
```

Теперь давайте создадим ещё одно окно, но с самого начала дадим ему имя: `yetanotherwindow`. Это делается с помощью вызова `screen` с ключом `-t`:\


```bash
$ screen -t yetanotherwindow
```

Перемещаться между окнами можно разными способами:

* С помощью Ctrl+a-n (перейти к _следующему_ окну) и Ctrl+a-p (перейти к _предыдущему_ окну).
* Используя Ctrl+a-_number_ (перейдите к окну с номером _number_).
* С помощью Ctrl+a-" можно просмотреть список всех окон. Вы можете перемещаться вверх и вниз с помощью клавиш со стрелками и выбрать нужное окно с помощью клавиши Enter:

```bash
Num Name                                                Flags

   0 bash                                             $
   1 ps                                                     $
   2 yetanotherwindow
```

При работе с окнами важно помнить следующее:

* Окна запускают свои программы полностью независимо друг от друга.
* Программы будут продолжать работать, даже если их окно не отображается (а также при отключении сеанса экрана, как мы вскоре увидим).

Чтобы удалить окно, просто закройте запущенную в нём программу (после удаления последнего окна `screen` закроется сама). В качестве альтернативы используйте Ctrl+a-k в окне, которое вы хотите удалить; вам будет предложено подтвердить действие:

```bash
Really kill this window [y/n]

Window 0 (bash) killed.
```

## **Регионы**

`screen` можно разделить экран терминала на несколько областей для размещения окон. Эти области могут быть горизонтальными (Ctrl+a-S) или вертикальными (Ctrl+a-|).

Единственное, что будет отображаться в новом регионе, — это `--` внизу, что означает, что он пуст:

```
 1 ps --
```

Чтобы перейти в новую область, введите Ctrl+a-Tab. Теперь вы можете добавить окно любым из способов, которые мы уже рассмотрели, например: Ctrl+a-2. Теперь `--` должно превратиться в `2 yetanotherwindow`:

```bash
$ ps                                                  $
  PID TTY          TIME CMD
 1020 pts/2    00:00:00 bash
 1033 pts/2    00:00:00 ps
$ screen -t yetanotherwindow




   1 ps                                                                2 yetanotherwindow
```

Важными аспектами, которые следует иметь в виду при работе с регионами, являются:

* Перемещаться между регионами можно, набирая Ctrl+a-Tab.
* Вы можете завершить все регионы, кроме текущего, с помощью Ctrl+a-Q.
* Вы можете завершить текущий регион с помощью Ctrl+a-X.
* Завершение работы региона не завершает работу связанного с ним окна.

## **Сеансы**

```bash
$ screen -list
There is a screen on:
        1037.pts-0.debian       (08/24/19 13:53:35)     (Attached)
1 Socket in /run/screen/S-carol.
```

Пока это наше единственное задание:

PID

`1037`

Имя

`pts-0.debian` (указывает на терминал — в нашем случае _псевдотерминальный подчинёный узел_ — и имя хоста).

Статус

`Attached`

Давайте создадим новый сеанс, дав ему более наглядное название:

```bash
$ screen -S "second session"
```

Экран терминала будет очищен, и вы увидите новую подсказку. Вы можете ещё раз проверить наличие сеансов:

```bash
$ screen -ls
There are screens on:
        1090.second session     (08/24/19 14:38:35)     (Attached)
        1037.pts-0.debian       (08/24/19 13:53:36)     (Attached)
2 Sockets in /run/screen/S-carol.
```

Чтобы завершить сеанс, закройте все его окна или просто введите команду `screen -S SESSION-PID -X quit` (вместо этого вы также можете указать имя сеанса). Давайте избавимся от нашего первого сеанса:\


```bash
$ screen -S 1037 -X quit
```

Вы вернётесь к командной строке за пределами `screen`. Но помните, что наш второй сеанс всё ещё активен:

```bash
$ screen -ls
There is a screen on:
	1090.second session	(08/24/19 14:38:35)	(Detached)
1 Socket in /run/screen/S-carol.
```

Однако, поскольку мы завершили родительский сеанс, ему присваивается новая метка: `Detached`.

**Сеанс Detachment**

По ряду причин вы можете захотеть отсоединить сеанс экрана от терминала:

* Чтобы ваш рабочий компьютер выполнял свои задачи, а вы подключались к нему удалённо из дома.
* Поделиться сеансом с другими пользователями.

Вы можете завершить сеанс с помощью комбинации клавиш Ctrl+a-d. Вы вернётесь в свой терминал:

```bash
[detached from 1090.second session]
$
```

Чтобы снова подключиться к сеансу, используйте команду `screen -r SESSION-PID`. В качестве альтернативы можно использовать `SESSION-NAME` как мы видели выше. Если есть только один отсоединённый сеанс, это необязательно:

```bash
$ screen -ls
There is a screen on:
        1090.second session      (08/24/19 14:38:35)     (Attached)
1 Socket in /run/screen/S-carol.
```

Важные параметры для повторного подключения сеанса:

`-d -r`

Повторно подключите сеанс и — при необходимости — сначала отсоедините его.

`-d -R`

То же, что и `-d -r` но `screen` сначала создаст сеанс, если его не существует.

`-d -RR`

То же, что и `-d -R`. Однако используйте первый сеанс, если доступно несколько.

`-D -r`

Повторно подключите сеанс. При необходимости сначала удаленно отключитесь и выйдите из системы.

`-D -R`

Если сеанс запущен, подключитесь к нему повторно (при необходимости сначала отделившись и выйдя из системы удалённо). Если сеанс не был запущен, создайте его и уведомите пользователя.

`-D -RR`

То же, что `-D -R` - только сильнее.

`-d -m`

Запустите `screen` в _отдельном режиме_. Это создаст новый сеанс, но не подключит к нему. Это полезно для сценариев запуска системы.

`-D -m`

То же, что и `-d -m`, но не создаёт новый процесс. Команда завершается, если сеанс завершается.

Прочтите страницы руководства, чтобы `screen` узнать о других вариантах.

## **Копирование и вставка: режим обратной прокрутки**

В GNU Screen есть функция копирования или _scrollback mode_. После входа в этот режим вы можете перемещать курсор в текущем окне и просматривать содержимое его истории с помощью клавиш со стрелками. Вы можете выделять текст и копировать его в другие окна. Для этого выполните следующие действия:

1. Войдите в режим copy/scrollback mode: Ctrl+a-\[.
2. Перейдите к началу фрагмента текста, который вы хотите скопировать, с помощью клавиш со стрелками.
3. Отметьте начало фрагмента текста, который вы хотите скопировать: Пробел.
4. С помощью клавиш со стрелками перейдите к концу фрагмента текста, который вы хотите скопировать.
5. Отметьте конец фрагмента текста, который вы хотите скопировать: Пробел.
6. Перейдите в выбранное вами окно и вставьте фрагмент текста: Ctrl+a-].

**Настройка экрана**

Файл конфигурации экрана для всей системы — `/etc/screenrc`. В качестве альтернативы можно использовать `~/.screenrc` на уровне пользователя. Файл включает четыре основных раздела конфигурации:

`SCREEN SETTINGS`

Вы можете задать общие настройки, указав _директиву_, за которой следует пробел и _значение_, например: `defscrollback 1024`.

`SCREEN KEYBINDINGS`

Этот раздел довольно интересен, так как позволяет переназначить сочетания клавиш, которые могут мешать вам при повседневном использовании терминала. Используйте ключевое слово `bind` с пробелом, символ, который нужно использовать после префикса команды, ещё один пробел и команду, например: `bind l kill` (этот параметр изменит способ закрытия окна по умолчанию на Ctrl+a-l).

Чтобы отобразить все сочетания клавиш, введите Ctrl+a-? или обратитесь к странице руководства.

{% hint style="info" %}
Конечно, вы также можете изменить сам префикс команды. Например, чтобы перейти от Ctrl+a к Ctrl+b, просто добавьте эту строку: `escape ^Bb`.
{% endhint %}

`TERMINAL SETTINGS`

В этом разделе представлены настройки, связанные с размерами окон терминала и буферами, среди прочего. Например, чтобы включить неблокирующий режим для более эффективной работы с нестабильными ssh-соединениями, используется следующая конфигурация: `defnonblock 5`.

`STARTUP SCREENS`

Вы можете включить команды для запуска различных программ при запуске `screen`; например: `screen -t top top` (на экране откроется окно с названием `top` и `top` внутри).

## tmux <a href="#tmux" id="tmux"></a>

`tmux` был выпущен в 2007 году. Несмотря на то, что он очень похож на `screen`, в нём есть несколько заметных отличий:

* Клиент-серверная модель: сервер предоставляет несколько сеансов, каждый из которых может иметь несколько связанных с ним окон, которыми, в свою очередь, могут совместно пользоваться разные клиенты.
* Интерактивный выбор сеансов, окон и клиентов с помощью меню.
* Одно и то же окно может быть связано с несколькими сеансами.
* Наличие раскладок клавиш как в _vim_, так и в _Emacs_.
* Поддержка UTF-8 и 256-цветного терминала.

## Окна

Вы можете вызвать его, просто введя `tmux` в командной строке. В нижней части окна появится приглашение оболочки и строка состояния:

```bash
[0] 0:bash*                                                        "debian" 18:53 27-Aug-19
```

Помимо `hostname` времени и даты, строка состояния предоставляет следующую информацию:

Название сеанса

`[0]`

Номер окна

`0:`

Название окна

`bash*`По умолчанию это название программы, запущенной в окне, и — в отличие от `screen` — `tmux` автоматически обновляется в соответствии с текущей запущенной программой. Обратите внимание на звёздочку, указывающую на то, что это текущее видимое окно.

Вы можете назначать имена сеанса и окна при вызове `tmux`:

```bash
$ tmux new -s "LPI" -n "Window zero"
```

Строка состояния изменится соответствующим образом:

```bash
[LPI] 0:Window zero*                                                 "debian" 19:01 27-Aug-19        
```

Префикс команды tmux — Ctrl+b. Чтобы создать новое окно, просто введите Ctrl+b-c; вы перейдете в новую командную строку, а в строке состояния отобразится новое окно:

```bash
[LPI] 0:Window zero- 1:bash*                                         "debian" 19:02 27-Aug-19
```

Поскольку Bash является базовой оболочкой, новое окно по умолчанию получает это имя. Запустите `top` и посмотрите, как меняется имя на `top`:

```bash
[LPI] 0:Window zero- 1:top*                                         "debian" 19:03 27-Aug-19
```

В любом случае вы можете переименовать окно с помощью Ctrl+b-,. При появлении запроса введите новое имя и нажмите Enter:

```
(rename-window) Window one
```

Вы можете отобразить все окна для выбора с помощью Ctrl+b-w (используйте клавиши со стрелками для перемещения вверх и вниз и enter для выбора):

```bash
(0)  0: Window zero- "debian"
(1)  1: Window one* "debian"
```

Подобно `screen` мы можем переходить от одного окна к другому с помощью:

Ctrl+b-n

перейдите к _следующему_ окну.

Ctrl+b-p

перейдите к _предыдущему_ окну.

Ctrl+b-_number_

перейдите в окно номер _number_.

Чтобы закрыть окно, используйте `Ctrl+b-&.` Вам будет предложено подтвердить действие:

```bash
kill-window Window one? (y/n)
```

Другие интересные оконные команды включают:

Ctrl+b-f

найдите окно по названию.

Ctrl+b-.

измените индексный номер окна.

Чтобы ознакомиться со всем списком команд, обратитесь к странице руководства.

## **Панели**

Функция разделения окна на части `screen` также присутствует в `tmux`. Однако полученные в результате разделения части называются не _регионами_, а _панелями_. Самое важное различие между регионами и панелями заключается в том, что последние являются полноценными псевдотерминалами, связанными с окном. Это означает, что при уничтожении панели будет уничтожен и её псевдотерминал, а также все связанные с ним программы.

## **Сеансы**

Для составления списка сеансов в `tmux` вы можете использовать Ctrl+b-s:

```bash
(0) + LPI: 2 windows (attached)
```

В качестве альтернативы вы можете использовать команду `tmux ls`:

```bash
$ tmux ls
LPI: 2 windows (created Tue Aug 27 19:01:49 2019) [158x39] (attached)
```

Есть только один сеанс (`LPI`), который включает в себя два окна. Давайте создадим новый сеанс из текущего. Это можно сделать с помощью Ctrl+b, введя `:new` в командной строке и нажав Enter. Вы будете перенаправлены в новый сеанс, что можно увидеть в строке состояния:

```
[2] 0:bash*                                                       "debian" 19:15 27-Aug-19
```

По умолчанию называется сессией `2`. Чтобы переименовать её, используйте Ctrl+b-$. При появлении запроса введите новое имя и нажмите Enter:

```
(rename-session) Second Session
```

Вы можете переключаться между сеансами с помощью Ctrl+b-s (используйте клавиши со стрелками и enter):

```
(0) + LPI: 2 windows
(1) + Second Session: 1 windows (attached)
```

Чтобы завершить сеанс, вы можете использовать команду `tmux kill-session -t SESSION-NAME`. Если вы введёте команду в текущем подключённом сеансе, вы выйдете из `tmux` и вернётесь в исходный сеанс терминала:

```
$ tmux kill-session -t "Second Session"
[exited]
$
```

**Сеансы detachment**

Убив `Second Session`, мы оказались за пределами `tmux`. Однако у нас всё ещё есть активный сеанс. Попросите `tmux` предоставить список сеансов, и вы наверняка найдёте его там:

```bash
$ tmux ls
LPI: 2 windows (created Tue Aug 27 19:01:49 2019) [158x39]
```

Однако этот сеанс отсоединён от терминала. Мы можем присоединить его с помощью `tmux attach -t SESSION-NAME` (`attach` можно заменить на `at` или просто — `a`). Если сеанс только один, указание имени необязательно:

```
$ tmux a
```

Теперь вы вернулись в свой сеанс; чтобы выйти из него, нажмите Ctrl+b-d:

```bash
[detached (from session LPI)]
$
```

{% hint style="info" %}
Один и тот же сеанс можно подключить более чем к одному терминалу. Если вы хотите подключить сеанс, предварительно отсоединив его от других терминалов, используйте переключатель `-d`: `tmux attach -d -t SESSION-NAME`.
{% endhint %}



Важные команды для подключения / отсоединения сеанса:

Ctrl+b-D

выберите, какой клиент отсоединить.

Ctrl+b-r

обновите клиентский терминал.

Чтобы ознакомиться со всем списком команд, обратитесь к странице руководства.

## **Копирование и вставка: режим обратной прокрутки**

Также есть режим копирования, в основном такой же, как в `screen` (не забывайте использовать префикс команды tmux, а не screen!). Единственное отличие в командах заключается в том, что для обозначения начала выделения используется Ctrl + пробел, а для копирования выделенного текста — Alt+w.

**Настройка tmux**

Файлы конфигурации для `tmux` обычно расположены по адресу `/etc/tmux.conf` и `~/.tmux.conf`. При запуске `tmux` используйте исходные файлы для этих файлов, если они существуют. Существует также возможность запуска `tmux` с помощью `-f` переключателя для предоставления альтернативного файла конфигурации. Вы можете найти `tmux` пример файла конфигурации, расположенный по адресу `/usr/share/doc/tmux/example_tmux.conf`. Уровень настройки, которого вы можете достичь, действительно высок. Некоторые из вещей, которые вы можете сделать, включают:

*   Измените префиксный ключ

    ```bash
    # Change the prefix key to C-a
    set -g prefix C-a
    unbind C-b
    bind C-a send-prefix
    ```
*   Установите дополнительные привязки клавиш для окон выше 9

    ```
    # Some extra key bindings to select higher numbered windows
    bind F1 selectw -t:10
    bind F2 selectw -t:11
    bind F3 selectw -t:12
    ```

Для получения полного списка всех привязок введите Ctrl+b-? (нажмите `q` для выхода) или обратитесь к странице руководства.

    На удалённом хосте: `ssh`` `_`local-username`_`@`_`local-ipaddress`_. После подключения к локальному компьютеру: `tmux ls`.
*   На удаленном хостинге подключитесь к `ssh` сеансу по имени:

    `tmux a -t ssh` (`a` может быть заменен на `at` или `attach`).
*   Вернувшись на свой локальный компьютер, подключитесь к сеансу `ssh` по имени, предварительно завершив соединение с удалённым хостом:

    `tmux a -d -t ssh` (`a` может быть заменен на `at` или `attach`).
*   Отобразите все сеансы для выбора и перейдите к первому сеансу (`[0]`). Там убейте сеанс `ssh` по имени:

    Мы вводим Ctrl+b-s, используем клавиши со стрелками для обозначения сеанса `0` и нажимаем enter `tmux kill-session -t ssh`.
*   Наконец, отключитесь от текущего сеанса и завершите его по имени:

    Ctrl+b-d `tmux kill-session -t 0`.

## Ответы на исследовательские упражнения <a href="#sec.103.5_02-aee" id="sec.103.5_02-aee"></a>

1. И `screen` и `tmux` могут войти в режим командной строки с помощью _префикса команды_ + : (мы уже видели краткий пример с `tmux`). Выполните следующие задачи в режиме командной строки:
   *   `screen` войдите в режим копирования:

       Ctrl+a-: — затем мы набираем `copy`.
   *   Создаем `tmux` переименовать текущее окно:

       Ctrl+b-: — затем мы набираем `rename-window`.
   *   Заставьте `screen` закрыть все окна и завершить сеанс:

       Ctrl+a-: — затем мы набираем `quit`.
   *   Как `tmux` разделить панель на две части:

       Ctrl+b-: — затем мы набираем `split-window`.
   *   Заставьте `tmux` закрыть текущее окно:

       Ctrl+b-: — затем мы набираем `kill-window`.
2. Когда вы входите в режим копирования в `screen`, вы можете использовать не только клавиши со стрелками и PgUp или PgDown для навигации по текущему окну и буферу прокрутки. Также можно использовать полноэкранный редактор, похожий на vi. С помощью этого редактора выполните следующие действия:
   *   Эхо-сигнал `supercalifragilisticexpialidocious` в вашем `screen` терминале:

       `echo supercalifragilisticexpialidocious`
   *   Теперь скопируйте пять последовательных символов (слева направо) в строке прямо над вашим курсором:

       Мы входим в режим копирования: Ctrl+a-\[ или Ctrl+a-: и затем вводим `copy`. Затем мы переходим на строку выше с помощью `k` и нажимаем space для обозначения начала выделения. Наконец, мы перемещаемся на четыре символа вперёд с помощью `l` и снова нажимаем space для обозначения конца выделения.
   *   Наконец, вставьте выделенное значение (`stice`) обратно в командную строку:

       Ctrl+a-]
3.  Предположим, вы хотите поделиться сеансом `tmux` (`our_session`) с другим пользователем. Вы создали сокет (`/tmp/our_socket`) с нужными разрешениями, чтобы и вы, и другой пользователь могли читать и писать. Какие ещё два условия должны быть выполнены, чтобы второй пользователь мог успешно подключиться к сеансу через `tmux -S /tmp/our_socket a -t our_session`?

    У обоих пользователей должна быть общая группа, например `multiplexer`. Затем мы должны изменить сокет на эту группу: `chgrp multiplexer /tmp/our_socket`.
