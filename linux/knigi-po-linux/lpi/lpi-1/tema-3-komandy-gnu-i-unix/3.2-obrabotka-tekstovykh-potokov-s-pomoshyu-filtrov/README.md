# 3.2 Обработка текстовых потоков с помощью фильтров

## Ключевые области знаний

* Отправка текстовых файлов и выходных потоков через текстовые фильтры для изменения вывода с помощью стандартных команд UNIX, входящих в пакет GNU textutils.

## Неполный список используемых файлов, терминов и утилит

* `bzcat`
* `cat`
* `cut`
* `head`
* `less`
* `md5sum`
* `nl`
* `od`
* `paste`
* `sed`
* `sha256sum`
* `sha512sum`
* `sort`
* `split`
* `tail`
* `tr`
* `uniq`
* `wc`
* `xzcat`
* `zcat`
