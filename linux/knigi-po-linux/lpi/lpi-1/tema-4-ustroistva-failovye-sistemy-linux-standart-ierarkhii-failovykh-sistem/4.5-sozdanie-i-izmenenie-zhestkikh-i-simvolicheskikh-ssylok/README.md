# 4.5 Создание и изменение жестких и символических ссылок

## Ключевые области знаний

* Создание ссылок.
* Определение жестких и / или программных ссылок.
* Копирование вместо связывания файлов.
* Использование ссылок для поддержки задач системного администрирования.

## Неполный список используемых файлов, терминов и утилит

* `ln`
* `ls`
