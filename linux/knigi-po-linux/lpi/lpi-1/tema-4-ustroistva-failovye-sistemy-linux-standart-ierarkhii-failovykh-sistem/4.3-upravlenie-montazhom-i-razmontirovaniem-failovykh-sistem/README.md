# 4.3 Управление монтажом и размонтированием файловых систем

## Ключевые области знаний

* Монтирование и размонтирование файловых систем вручную.
* Настройка подключения файловой системы при загрузке.
* Настройка подключаемых пользователем съемных файловых систем.
* Использование меток и UUID для идентификации и монтирования файловых систем.
* Осведомленность о блоках монтирования systemd.

## Неполный список используемых файлов, терминов и утилит

* `/etc/fstab`
* `/media/`
* `mount`
* `umount`
* `blkid`
* `lsblk`
