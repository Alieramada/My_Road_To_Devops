# 4.4 Управление разрешениями для файлов и правами собственности

## Ключевые области знаний

* Управление разрешениями доступа к обычным и специальным файлам, а также каталогам.
* &#x20;Использовние таких режимов доступа, как suid, sgid и sticky bit.
* Изменение маски создания файла.
* Использовние поля "Группа", чтобы предоставить доступ к файлам членам группы.

## Неполный список используемых файлов, терминов и утилит

* `chmod`
* `umask`
* `chown`
* `chgrp`
