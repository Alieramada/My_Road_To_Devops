# 4.2 Поддержание целостности файловых систем

Ключевые области знаний

* Проверка целостности файловых систем.
* Следить за свободным пространством и индексными индексами.
* Устранять простые проблемы с файловой системой.

Неполный список используемых файлов, терминов и утилит

* `du`
* `df`
* `fsck`
* `e2fsck`
* `mke2fs`
* `tune2fs`
* `xfs_repair`
* `xfs_fsr`
* `xfs_db`
