# 4.1 Создание разделов и файловых систем

## Ключевые области знаний

* Управление таблицами разделов MBR и GPT
* Использование различных команд `mkfs` для создания различных файловых систем, таких как:
  * ext2/ ext3 /ext4
  * XFS
  * VFAT
  * exFAT
* Базовые знания о возможностях Btrfs, включая файловые системы с несколькими устройствами, сжатие и подтома.

Неполный список используемых файлов, терминов и утилит

* `fdisk`
* `gdisk`
* `parted`
* `mkfs`
* `mkswap`
