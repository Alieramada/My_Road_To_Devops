# 4.6 Поиск системных файлов и расположение их в нужных местах

## Ключевые области знаний

* Понимание правильного расположения файлов в соответствии с FHS.
* Поиск файлов и команд в системе Linux.
* Знание расположенияи назначения важных файлов и каталогов, указанных в FHS.

## Неполный список используемых файлов, терминов и утилит

* `find`
* `locate`
* `updatedb`
* `whereis`
* `which`
* `type`
* `/etc/updatedb.conf`
