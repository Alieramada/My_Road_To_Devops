# 10.2 Настройка безопасности хоста

## Ключевые области знаний

* Осведомленность о теневых паролях и о том, как они работают.
* Отключение неиспользуемых сетевых служб.
* Понимание роли TCP оболочеку.

Неполный список используемых файлов, терминов и утилит

* `/etc/nologin`
* `/etc/passwd`
* `/etc/shadow`
* `/etc/xinetd.d/`
* `/etc/xinetd.conf`
* `systemd.socket`
* `/etc/inittab`
* `/etc/init.d/`
* `/etc/hosts.allow`
* `/etc/hosts.deny`
