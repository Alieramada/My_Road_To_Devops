# 5.1 Настройка и использование среды shell

## Ключевые области знаний

* Задание переменных среды (например, `PATH`) при входе в систему или при запуске новой оболочки.
* Написание функции Bash для часто используемых последовательностей команд.
* Поддержка каталогов-шаблонов(skeleton) для новых учётных записей пользователей
* Установка пути поиска команд с правильным каталогом.

## Неполный список используемых файлов, терминов и утилит

* `.`
* `source`
* `/etc/bash.bashrc`
* `/etc/profile`
* `env`
* `export`
* `set`
* `unset`
* `~/.bash_profile`
* `~/.bash_login`
* `~/.profile`
* `~/.bashrc`
* `~/.bash_logout`
* `function`
* `alias`
