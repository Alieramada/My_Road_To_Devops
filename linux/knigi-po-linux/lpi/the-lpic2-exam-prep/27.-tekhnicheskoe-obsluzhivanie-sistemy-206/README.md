# 27. Техническое обслуживание системы (206)

## **27.1  Задача 206.1; Создание и установка программ из исходного кода (4 балла)** <a href="#objective-2061-make-and-install-programs-from-source-4-points" id="objective-2061-make-and-install-programs-from-source-4-points"></a>

* Кандидаты должны уметь создавать и устанавливать исполняемую программу из исходного кода. Эта задача включает в себя умение распаковывать файл с исходным кодом.

## **27.2 Задача 206.2; Резервное копирование (3 балла)** <a href="#objective-2062-backup-operations-3-points" id="objective-2062-backup-operations-3-points"></a>

* Кандидаты должны уметь использовать системные инструменты для резервного копирования важных системных данных.

## **27.3 Задача 206.3; Уведомление пользователей о проблемах, связанных с системой (1 балл)** <a href="#objective-2063-notifying-users-on-system-related-issues-1-point" id="objective-2063-notifying-users-on-system-related-issues-1-point"></a>

* Кандидаты должны иметь возможность уведомлять пользователей о текущих проблемах, связанных с системой.
