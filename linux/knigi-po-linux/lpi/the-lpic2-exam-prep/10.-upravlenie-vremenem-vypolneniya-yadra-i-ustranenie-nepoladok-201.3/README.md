# 10. Управление временем выполнения ядра и устранение неполадок (201.3)

Кандидаты должны уметь управлять ядром 2.6.x, 3.x или 4.x и его загружаемыми модулями и/или запрашивать их. Кандидаты должны уметь выявлять и устранять распространенные проблемы при загрузке и во время выполнения. Кандидаты должны разбираться в обнаружении устройств и управлении ими с помощью udev. Эта цель включает в себя устранение неполадок с правилами udev.
