# 10.6 Информация об аппаратном обеспечении и ядре

## 10.6.1 uname

uname выводит системную информацию, такую как тип компьютера, имя сетевого хоста, выпуск операционной системы, название операционной системы, версия операционной системы и тип процессора хоста.&#x20;

Параметры:&#x20;

-a ; --all

Выведет всю информацию в указанном ниже порядке, за исключением -p и -i, если они неизвестны.

-s ; --kernel-name

выводит имя ядра

-n ; --nodename

выводит имя сетевого узла hostname

-r ; --kernel-release

выводит версию ядра

-v ; --kernel-version

выводит версию сборки ядра, дату и время

-m ; --machine

выводит название аппаратной архитектуры компьютера

-p ; --processor

выводит название типа процессора

i ; --hardware-platform

выводит название аппаратной платформы

-o ; --operating-system

выводит название операционной системы

Пример:

```bash
pirog@pirog:/lib/modules$ uname -a
Linux pirog 6.11.0-17-generic #17~24.04.2-Ubuntu SMP PREEMPT_DYNAMIC Mon Jan 20 22:48:29 UTC 2 x86_64 x86_64 x86_64 GNU/Linux

```

## 10.6.2 /proc/stys/kernel

/proc/sys/kernel/ - это каталог в псевдофайловой системе /proc. Он содержит файлы, которые позволяют настраивать ядро Linux и контролировать его работу. Будьте осторожны, так как изменение некоторых файлов может привести к зависанию или нарушению работы системы. Поскольку эти параметры сильно зависят от версий ядра, рекомендуется ознакомиться как с документацией, так и с исходным кодом, прежде чем вносить изменения. Смотрите также раздел, посвященный файловой системе /proc.

Некоторые файлы совершенно безвредны и могут быть безопасно использованы для получения информации, например, для отображения версии запущенного ядра:

```bash
pirog@pirog:/lib/modules$ cat /proc/sys/kernel/osrelease
6.11.0-17-generic
```

Некоторые файлы могут быть использованы для установки информации в ядре. Например, следующее сообщение сообщит ядру, что оно не запускает аварийный цикл, а автоматически перезагружается через 20 секунд:

```bash
root@pirog:~# echo 20 > /proc/sys/kernel/panic
```

## 10.6.3 lspc

С помощью lspci вы можете отображать информацию обо всех шинах PCI в системе и обо всех подключенных к ним устройствах. Имейте в виду, что у вас должно быть ядро Linux версии 2.1.82 или новее. В старых ядрах прямой аппаратный доступ доступен только для пользователей с правами root. Чтобы сделать вывод lspci более подробным, можно добавить один или несколько параметров -v (до 3). Во многих операционных системах доступ к некоторым частям пространства конфигурации PCI ограничен правами root. Таким образом, возможности lspci, доступные обычным пользователям, ограничены.

## 10.6.5 lsdev

lsdev lsdev отображает информацию об установленном оборудовании. Он собирает информацию о прерываниях, файлах DMA и прерываниях из каталога /proc. lsdev предоставляет краткий обзор того, какое устройство использует какой адрес ввода-вывода и каналы IRQ/DMA. Используемые файлы:

```bash
/proc/interrupts
/proc/ioports
/proc/dma
```

## 10.6.6 sysctl

sysctl используется для изменения параметров ядра во время выполнения. Доступные параметры перечислены в каталоге /proc/sys/ . Файл конфигурации обычно можно найти в /etc/sysctl.conf . Важно знать, что модули, загруженные после использования sysctl, могут переопределять его настройки. Вы можете предотвратить это, запустив sysctl только после загрузки всех модулей.
