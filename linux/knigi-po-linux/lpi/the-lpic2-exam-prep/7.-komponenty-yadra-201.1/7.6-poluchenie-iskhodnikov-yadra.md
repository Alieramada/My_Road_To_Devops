# 7.6 Получение исходников ядра

Исходные тексты ядра почти для всех версий ядра можно найти в [архивах](../../../../../) ядра Linux.

Имена файлов в архиве ядра Linux соответствуют правилам нумерации версий ядра. Например: Формат имени файла для версий ядра 3.0 и 4.0 - linux- kernel-version .tar.xz Таким образом, linux-3.18.43.tar.xz - это архив ядра для версии "3.18.43".

Используемым соглашением о нумерации версий для ядер 3.0 и 4.0 является linux- A.B.C .tar.xz, где:

* A обозначает версию ядра. Она меняется только при значительных изменениях в коде и концепции.&#x20;
* B обозначает ревизию.&#x20;
* C - номер исправления.

Смотрите параграф, посвященный [нумерации](7.3-obzor-skhem-numeracii-yader-i-ispravlenii.md) версий ядра, чтобы узнать больше о различных соглашениях, которые используются в настоящее время.

Обычно для хранения и распаковки исходных текстов ядра используется каталог `/usr/src` . Вы можете использовать другое расположение, если создадите символическую ссылку из своего нового каталога исходных текстов на `/usr/src/linux`.

Исходный код ядра доступен в виде сжатого архива tar в формате xz (расширение .xz). Распакуйте архив с помощью unxz . Полученный архив tar можно распаковать с помощью утилиты tar, например:

```bash
unxz linux-3.18.43.tar.xz
tar xvf linux-3.18.43.tar
```

Вы также можете распаковать и распаковать tar за один шаг, используя опцию J:

```bash
tar Jxvf linux-3.18.43.tar.xz
```

{% hint style="info" %}
Для получения дополнительной информации обратитесь к справочным страницам tar и, xz.
{% endhint %}
