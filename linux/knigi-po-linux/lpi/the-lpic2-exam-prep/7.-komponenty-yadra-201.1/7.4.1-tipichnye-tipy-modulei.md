# 7.4.1 Типичные типы модулей

* block

Модули для нескольких блочных устройств, таких как RAID-контроллеры или IDE tape

* cd-rom

Модули драйверов устройств для нестандартных приводов CD-ROM.

* fs

Драйверы для файловых систем, таких как MS-DOS (модуль msdos.ko)

* ipv4&#x20;

Включает в себя модульные функции ядра, связанные с обработкой IP-адресов, такие как маскарадинг IP-адресов

* misc

Все, что не помещается ни в один из других подкаталогов, попадает сюда. Обратите внимание, что в верхней части этого дерева не хранятся модули

* net

Модули драйверов сетевого интерфейса

* scsi

Содержит модули драйверов для SCSI-контроллера

* video

Специальные модули драйверов для видеоадаптеров

Каталоги модулей также называются тегами в контексте команд управления модулями.
