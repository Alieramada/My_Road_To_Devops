# 7.5 Компиляция ядра Linux (201.2)

Кандидаты должны уметь правильно настраивать ядро, чтобы при необходимости включать или отключать определенные функции ядра Linux. Эта задача включает в себя компиляцию и перекомпиляцию ядра Linux по мере необходимости, обновление и фиксацию изменений в новом ядре, создание исходного образа и установку новых ядер.

## 7.5.1 Ключевые области знаний

* /usr/src/linux/
* Makefiles ядра
* Ядра 2.6.x, 3.x и 4.x make цели
* Настройка текущей конфигурации ядра
* Создание нового ядра и соответствующих модулей ядра
* Установка нового ядра и любых модулей
* Убедитесь, что диспетчер загрузки может найти новое ядро и связанные с ним файлы
* Файлы конфигурации модуля
* Использование DKMS для компиляции модулей ядра
* Осведомленность о dracut
