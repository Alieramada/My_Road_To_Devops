# 7.10 Установка нового ядра

Когда новое ядро будет скомпилировано, система может быть настроена на его загрузку.

Сначала вам нужно поместить копию нового bzImage в загрузочный каталог (который должен находиться в отдельном загрузочном разделе). Для наглядности название файла ядра должно содержать номер версии ядра, например: vmlinuz-2.6.31 :

```bash
# cp /usr/src/linux/arch/x86_64/boot/bzImage
 /boot/vmlinuz-2.6.31
```

Это также гарантирует, что у вас может быть более одной версии ядра в каталоге /boot, например, если вам нужно загрузить более старое ядро из-за проблем с новым.&#x20;

После перемещения файла ядра в нужное место вам нужно будет настроить диспетчер загрузки (GRUB), чтобы он мог загружать новое ядро.&#x20;

Более подробную информацию о GRUB можно найти в разделе grub.

Либо make install записывает необходимые файлы в /boot и модифицирует grub, настраивая всё

```
[root@server1 linux]# make install
sh ./arch/x86/boot/install.sh 4.14.3 arch/x86/boot/bzImage \
    System.map "/boot"
[root@server1 linux]# uname -r
3.10.0-693.el7.x86_64
перезагрузитесь и наслаждайтесь своим новым ядром!

[root@server1 ~]# uname -r
4.14.3
```
