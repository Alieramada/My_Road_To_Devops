# 5.7 Осведомленность о других инструментах мониторинга

Существуют инструменты мониторинга, которые доступны как в открытом исходном коде (в основных версиях), так и в корпоративных версиях или интегрированы с другими продуктами с точки зрения предприятия. Они предлагают поддержку и дополнительные функции.

## Nagios

Nagios был доступен с конца 90-х — начала 2000-х годов. По сути, это набор продуктов.

[![](https://github.com/Borosan/lpic2book/raw/master/.gitbook/assets/nagio-logo.PNG)](https://github.com/Borosan/lpic2book/blob/master/.gitbook/assets/nagio-logo.PNG)

* Nagios Core : свободно доступная система мониторинга ядра с открытым исходным кодом.
* Collectd-nagios plugin : запрашивает информацию у демона collectd, а затем создаёт красивые графики на панели мониторинга nagios.
* Nagios XI : Полный корпоративный пакет.
* Сервер Журналов nagios
* Сетевой анализатор Nagios
* Nagios Fusion
* ...

веб-сайт: [https://www.nagios.com](https://www.nagios.com/)

## MRTG



Multi Router Traffic Grapher (MRTG) — это инструмент для сетевых администраторов, который предлагает корпоративные расширения для MRTG, включая Scrutinizer, FlowPro и репликатор.

[![](https://github.com/Borosan/lpic2book/raw/master/.gitbook/assets/mrtg-logo.gif)](https://github.com/Borosan/lpic2book/blob/master/.gitbook/assets/mrtg-logo.gif)

MRTG отслеживает нагрузку на сеть, считывает трафик и создаёт статистику на основе информации с маршрутизаторов и коммутаторов, а также создаёт журналы для последующего использования. Он написан на Perl. Он работает в Unix, Linux и Windows

[![](https://github.com/Borosan/lpic2book/raw/master/.gitbook/assets/mrtg-Scrutinizer-logo.png)](https://github.com/Borosan/lpic2book/blob/master/.gitbook/assets/mrtg-Scrutinizer-logo.png)

[![](https://github.com/Borosan/lpic2book/raw/master/.gitbook/assets/mrtg-flowpro-logo.png)](https://github.com/Borosan/lpic2book/blob/master/.gitbook/assets/mrtg-flowpro-logo.png)

[![](https://github.com/Borosan/lpic2book/raw/master/.gitbook/assets/mrtg-replicator-logo.png)](https://github.com/Borosan/lpic2book/blob/master/.gitbook/assets/mrtg-replicator-logo.png)

веб-сайт: [https://www.mrtg.com /](https://www.mrtg.com/)

## Cacti&#x20;

Cacti — это комплексное решение для построения сетевых графиков, разработанное для использования возможностей хранения данных и построения графиков в RRDTool. Cacti предоставляет быстрый опрос, расширенные шаблоны графиков, несколько способов сбора данных и функции управления пользователями. Все это заключено в интуитивно понятный и простой в использовании интерфейс, который подходит как для локальных сетей, так и для сложных сетей с тысячами устройств.

[![](https://github.com/Borosan/lpic2book/raw/master/.gitbook/assets/cacti-logo.png)](https://github.com/Borosan/lpic2book/blob/master/.gitbook/assets/cacti-logo.png)

Cacti можно использовать вместе с collectd, поскольку они оба используют rrdTools.

веб-сайт: [https://www.cacti.net /](https://www.cacti.net/)
