# 5.3 Мониторинг ИТ-инфраструктуры

Одним из инструментов, которые можно использовать для мониторинга ИТ-инфраструктуры, является collectd. collectd - это демон, который периодически собирает статистику производительности системы и предоставляет механизмы для сохранения значений различными способами. Он собирает статистику о системе, в которой он запущен, и сохраняет эту информацию. Затем эти статистические данные могут быть использованы для выявления текущих проблем с производительностью (т.е. для анализа производительности) и прогнозирования будущей нагрузки на систему (т.е. для планирования производительности). collectd написан на C для повышения производительности и мобильность, позволяет запускать его в системах без языка сценариев или демона cron, таких как встроенные системы. Обратите внимание, что collectd только собирает данные, для отображения собранных данных требуются дополнительные инструменты.

Также для измерения, сбора и отображения статистики производительности ресурсов можно использовать другие инструменты мониторинга, такие как Icinga2, Nagios, MRTG и Cacti . Использование инструмента мониторинга может помочь вам выявить возможные узкие места, связанные с измеряемыми ресурсами, а также спрогнозировать будущий рост.
