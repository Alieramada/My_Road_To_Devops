# 5.2 Диагностика использования ресурсов

Используя инструменты и знания, представленные в предыдущих двух главах, можно будет диагностировать использование ресурсов для конкретных компонентов или процессов. Одним из упомянутых инструментов был sar, который способен регистрировать измерения за более длительный период времени. Возможность использовать записанные данные для анализа тенденций является одним из преимуществ использования инструмента, способного регистрировать измерения.
