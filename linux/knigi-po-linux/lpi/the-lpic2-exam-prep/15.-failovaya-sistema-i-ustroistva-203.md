# 15. Файловая система и устройства (203)

Этот раздел оценивается в 9 баллов и содержит следующие три задачи:&#x20;

### **15.1. Задача 203.1. Работа с файловой системой Linux (4 балла)**&#x20;

Кандидаты должны уметь правильно настраивать стандартную файловую систему Linux и ориентироваться в ней. Эта задача включает в себя настройку и монтирование различных типов файловых систем.&#x20;

### **15.2 Задача 203.2: Поддержка файловой системы Linux (3 балла)**&#x20;

Кандидаты должны уметь правильно поддерживать файловую систему Linux с помощью системных утилит. Эта цель включает в себя манипулирование стандартными файловыми системами и мониторинг интеллектуальных устройств.&#x20;

### **15.3 Задача 203.3; Создание и настройка параметров файловой системы (2 балла)**&#x20;

Кандидаты должны уметь настраивать файловые системы автоматического монтирования с помощью AutoFS. Эта задача включает в себя настройку автоматического монтирования для файловых систем сети и устройств. Также в программу входит создание файловых систем для таких устройств, как компакт-диски, и базовые знания о зашифрованных файловых системах.
