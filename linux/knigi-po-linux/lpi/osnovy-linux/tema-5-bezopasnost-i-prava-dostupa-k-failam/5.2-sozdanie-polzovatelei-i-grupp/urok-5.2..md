# Урок 5.2.

## Введение <a href="#sec.5.2_01-in" id="sec.5.2_01-in"></a>

Управление пользователями и группами на компьютере с Linux — один из ключевых аспектов системного администрирования. По сути, Linux — это многопользовательская операционная система, в которой несколько пользователей могут одновременно работать на одном компьютере.

Информация о пользователях и группах хранится в четырёх файлах в дереве каталогов `/etc/`:

`/etc/passwd`

файл из семи полей, разделенных двоеточием, содержащий основную информацию о пользователях

`/etc/group`

файл из четырех полей, разделенных двоеточием, содержащий основную информацию о группах

`/etc/shadow`

файл из девяти полей, разделенных двоеточиями, содержащих зашифрованные пароли пользователей

`/etc/gshadow`

файл из четырех полей, разделенных двоеточием, файл, содержащий зашифрованные групповые пароли

Все эти файлы обновляются с помощью набора инструментов командной строки для управления пользователями и группами, о которых мы поговорим позже в этом уроке. Ими также можно управлять с помощью графических приложений, характерных для каждого дистрибутива Linux, которые предоставляют более простые и удобные интерфейсы управления.

{% hint style="info" %}
Даже если файлы представляют собой обычный текст, не редактируйте их напрямую. Для этого всегда используйте инструменты, поставляемые с вашим дистрибутивом.
{% endhint %}

## Файл `/etc/passwd` <a href="#the_file_etcpasswd" id="the_file_etcpasswd"></a>

`/etc/passwd` Это доступный для чтения всем пользователям файл, содержащий список пользователей, каждый из которых указан в отдельной строке:

```bash
frank:x:1001:1001::/home/frank:/bin/bash
```

Каждая строка состоит из семи полей, разделенных двоеточием:

_Имя пользователя_

Имя, используемое при входе пользователя в систему.

_Пароль_

Зашифрованный пароль (или `x`, если используются теневые пароли).

_Идентификатор пользователя (UID)_

Идентификационный номер, присвоенный пользователю в системе.

_Идентификатор группы (GID)_

Основной групповой номер пользователя в системе.

_GECOS_

Дополнительное поле для комментариев, которое используется для добавления дополнительной информации о пользователе (например, полного имени). Поле может содержать несколько записей, разделённых запятыми.

_Домашний каталог_

Абсолютный путь к домашнему каталогу пользователя.

_Оболочка_

Абсолютный путь к программе, которая автоматически запускается при входе пользователя в систему (обычно это интерактивная оболочка, например `/bin/bash`).

## Файл `/etc/group` <a href="#the_file_etcgroup" id="the_file_etcgroup"></a>

`/etc/group` Это файл, доступный для чтения всем, который содержит список групп, каждая из которых указана в отдельной строке:

```sh
developer:x:1002:
```

Каждая строка состоит из четырех полей, разделенных двоеточием:

_Название группы_

Название группы.

_Групповой пароль_

Зашифрованный пароль группы (или `x` при использовании теневых паролей).

_Идентификатор группы (GID)_

Идентификационный номер, присвоенный группе в системе.

_Список участников_

Список пользователей, входящих в группу, разделённый запятыми, за исключением тех, для кого эта группа является основной.

## Файл `/etc/shadow` <a href="#the_file_etcshadow" id="the_file_etcshadow"></a>

`/etc/shadow` Это файл, доступный только для чтения пользователю root и пользователям с правами root. Он содержит зашифрованные пароли пользователей, каждый из которых находится в отдельной строке:

```sh
frank:$6$i9gjM4Md4MuelZCd$7jJa8Cd2bbADFH4dwtfvTvJLOYCCCBf/.jYbK1IMYx7Wh4fErXcc2xQVU2N1gb97yIYaiqH.jjJammzof2Jfr/:18029:0:99999:7:::
```

Каждая строка состоит из девяти полей, разделенных двоеточием:

_Имя пользователя_

Имя, используемое при входе пользователя в систему.

_Зашифрованный пароль_

Зашифрованный пароль пользователя (если значение равно `!`, учётная запись заблокирована).

_Дата последней смены пароля_

Дата последнего изменения пароля в виде количества дней с 01.01.1970. Значение `0` означает, что пользователь должен изменить пароль при следующем входе в систему.

_Минимальный возраст пароля_

Минимальное количество дней после смены пароля, которое должно пройти, прежде чем пользователю будет разрешено снова сменить пароль.

_Максимальный возраст пароля_

Максимальное количество дней, которое должно пройти, прежде чем потребуется смена пароля.

_Период предупреждения о введении пароля_

Количество дней до истечения срока действия пароля, в течение которых пользователь получает предупреждение о необходимости смены пароля.

_Период бездействия пароля_

Количество дней после истечения срока действия пароля, в течение которых пользователь должен обновить пароль. По истечении этого срока, если пользователь не изменит пароль, учётная запись будет отключена.

_Срок действия учетной записи истек_

Дата в виде количества дней, прошедших с 01.01.1970, по истечении которых учётная запись пользователя будет отключена. Пустое поле означает, что срок действия учётной записи пользователя не ограничен.

_Зарезервированное поле_

Поле, которое зарезервировано для использования в будущем.

## Файл `/etc/gshadow` <a href="#the_file_etcgshadow" id="the_file_etcgshadow"></a>

`/etc/gshadow` Это файл, доступный только для чтения пользователю root и пользователям с правами root, который содержит зашифрованные пароли для групп, каждый в отдельной строке:

```sh
разработчик:$6$7QUIhUX1WdO6$H7kOYgsboLkDseFHpk04lwAtweSUQHipoxIgo83QNDxYtYwgmZTCU0qSCuCkErmyR263rvHiLctZVDR7Ya9Ai1::
```

Каждая строка состоит из четырех полей, разделенных двоеточием:

_Название группы_

Название группы.

_Зашифрованный пароль_

Зашифрованный пароль для группы (используется, когда пользователь, не являющийся членом группы, хочет присоединиться к группе с помощью команды `newgrp` — если пароль начинается с `!`, доступ к группе с помощью `newgrp` запрещён).

_Администраторы групп_

Список администраторов группы, разделённый запятыми (они могут изменить пароль группы, а также добавлять или удалять участников группы с помощью команды `gpasswd`).

_Участники группы_

Список участников группы, разделенный запятыми.

Теперь, когда мы узнали, где хранится информация о пользователях и группах, давайте поговорим о наиболее важных инструментах командной строки для обновления этих файлов.

## Добавление и удаление учетных записей пользователей <a href="#adding_and_deleting_user_accounts" id="adding_and_deleting_user_accounts"></a>

В Linux вы добавляете новую учётную запись пользователя с помощью команды `useradd` и удаляете учётную запись пользователя с помощью команды `userdel`

Если вы хотите создать новую учётную запись пользователя с именем `frank` с настройками по умолчанию, выполните следующие действия:

```sh
# useradd frank
```

После создания нового пользователя вы можете установить пароль с помощью `passwd`:

```sh
# passwd frank
Changing password for user frank.
New UNIX password:
Retype new UNIX password:
passwd: all authentication tokens updated successfully.
```

Для выполнения обеих этих команд требуются права суперпользователя. При выполнении команды `useradd` информация о пользователе и группе, хранящаяся в базах данных паролей и групп, обновляется для вновь созданной учётной записи пользователя, и, если указано, создаётся домашний каталог нового пользователя, а также группа с тем же именем, что и у учётной записи пользователя.

{% hint style="info" %}
Помните, что вы всегда можете использовать утилиту `grep` для фильтрации баз данных паролей и групп, отображая только записи, относящиеся к конкретному пользователю или группе. В приведённом выше примере вы можете использовать

`cat /etc/passwd | grep frank`

или

`grep frank /etc/passwd`

чтобы просмотреть основную информацию о вновь созданной `frank` учетной записи.
{% endhint %}

Наиболее важными параметрами, применимыми к команде `useradd` , являются:

`-c`

Создайте новую учетную запись пользователя с пользовательскими комментариями (например, полное имя).

`-d`

Создайте новую учетную запись пользователя с пользовательским домашним каталогом.

`-e`

Создайте новую учётную запись пользователя, указав конкретную дату, когда она будет отключена.

`-f`

Создайте новую учётную запись пользователя, указав количество дней после истечения срока действия пароля, в течение которых пользователь должен обновить пароль.

`-g`

Создайте новую учетную запись пользователя с определенным GID

`-G`

Создайте новую учетную запись пользователя, добавив ее в несколько дополнительных групп.

`-m`

Создайте новую учетную запись пользователя с его домашним каталогом.

`-M`

Создайте новую учетную запись пользователя без ее домашнего каталога.

`-s`

Создайте новую учетную запись пользователя с определенной оболочкой входа.

`-u`

Создайте новую учетную запись пользователя с определенным UID.

После создания новой учётной записи пользователя вы можете использовать команды `id` и `groups` для определения её UID, GID и групп, к которым она принадлежит.

```sh
# id frank
uid=1000(frank) gid=1000(frank) groups=1000(frank)
# groups frank
frank : frank
```

{% hint style="info" %}
Не забудьте проверить и при необходимости отредактировать файл `/etc/login.defs`, в котором определяются параметры конфигурации, управляющие созданием пользователей и групп. Например, вы можете задать диапазон UID и GID, которые могут быть присвоены новым учётным записям пользователей и групп, указать, что вам не нужно использовать опцию `-m` для создания домашнего каталога нового пользователя, а также указать, должна ли система автоматически создавать новую группу для каждого нового пользователя.
{% endhint %}

Если вы хотите удалить учётную запись пользователя, вы можете использовать команду `userdel` . В частности, эта команда обновляет информацию, хранящуюся в базах данных учётных записей, удаляя все записи, относящиеся к указанному пользователю. Опция `-r` также удаляет домашний каталог пользователя и всё его содержимое, а также почтовый ящик пользователя. Другие файлы, расположенные в других местах, необходимо искать и удалять вручную.

```sh
# userdel -r frank
```

Как и прежде, вам нужны права root для удаления учетных записей пользователей.

## Skeleton каталог <a href="#the_skeleton_directory" id="the_skeleton_directory"></a>

Когда вы добавляете новую учётную запись пользователя, даже если вы создаёте её домашний каталог, новый домашний каталог заполняется файлами и папками, которые копируются из каталога-основы (по умолчанию `/etc/skel`). Идея проста: системный администратор хочет добавить новых пользователей с одинаковыми файлами и папками в домашнем каталоге. Поэтому, если вы хотите изменить файлы и папки, которые автоматически создаются в домашнем каталоге новых учётных записей пользователей, вы должны добавить эти новые файлы и папки в каталог-основу.

{% hint style="info" %}
Обратите внимание, что файлы профилей, которые обычно находятся в каталоге-скелете, являются скрытыми файлами. Поэтому, если вы хотите вывести список всех файлов и папок в каталоге-скелете, которые будут скопированы в домашний каталог вновь созданных пользователей, вам нужно использовать команду `ls -al`
{% endhint %}

#### Добавление и удаление групп <a href="#adding_and_deleting_groups" id="adding_and_deleting_groups"></a>

Что касается управления группами, вы можете добавлять или удалять группы с помощью команд `groupadd` и `groupdel`.

Если вы хотите создать новую группу с именем `developer`, вы можете выполнить следующую команду от имени пользователя root:

```sh
# groupadd -g 1090 developer
```

Параметр `-g` этой команды создает группу с определенным идентификатором GID.

Если вы хотите удалить `developer` группу, вы можете выполнить следующее:

```sh
# groupdel developer
```

{% hint style="info" %}
Помните, что при добавлении новой учётной записи пользователя основная группа и дополнительные группы, к которым она относится, должны существовать до запуска команды `useradd` . Кроме того, вы не можете удалить группу, если она является основной группой учётной записи пользователя.
{% endhint %}

## Команда `passwd` <a href="#the_passwd_command" id="the_passwd_command"></a>

Эта команда в основном используется для изменения пароля пользователя. Любой пользователь может изменить свой пароль, но только root может изменить пароль любого другого пользователя.

В зависимости от используемой опции `passwd` вы можете управлять конкретными аспектами устаревания паролей:

`-d`

Удалите пароль учётной записи пользователя (таким образом установив пустой пароль и сделав учётную запись без пароля).

`-e`

Принудительно измените пароль учетной записи пользователя.

`-l`

Заблокируйте учётную запись пользователя (перед зашифрованным паролем стоит восклицательный знак).

`-u`

Разблокируйте учетную запись пользователя (при этом будет удален восклицательный знак).

`-S`

Выведите информацию о состоянии пароля для конкретной учетной записи.

Эти параметры доступны только для пользователя root. Чтобы увидеть полный список параметров, обратитесь к справочным страницам.

### Упражнения с руководством <a href="#sec.5.2_01-ge" id="sec.5.2_01-ge"></a>

2.  Обратите внимание на следующие выходные данные, чтобы ответить на следующие семь вопросов:

    ```sh
    # cat /etc/passwd | tail -3
    dave:x:1050:1050:User Dave:/home/dave:/bin/bash
    carol:x:1051:1015:User Carol:/home/carol:/bin/sh
    henry:x:1052:1005:User Henry:/home/henry:/bin/tcsh
    # cat /etc/group | tail -3
    web_admin:x:1005:frank,emma
    web_developer:x:1010:grace,kevin,christian
    dave:x:1050:
    # cat /etc/shadow | tail -3
    dave:$6$AbCdEfGh123456789A1b2C3D4e5F6G7h8i9:0:20:90:7:30::
    carol:$6$q1w2e3r4t5y6u7i8AbcDeFgHiLmNoPqRsTu:18015:0:60:7:::
    henry:!$6$123456789aBcDeFgHa1B2c3d4E5f6g7H8I9:18015:0:20:5:::
    # cat /etc/gshadow | tail -3
    web_admin:!:frank:frank,emma
    web_developer:!:kevin:grace,kevin,christian
    dave:!::
    ```

    * Каков идентификатор пользователя (UID) и идентификатор группы (GID) `carol`?
    * Какая оболочка установлена для `dave` и `henry`?
    * Как называется основная группа `henry`?
    * Кто входит в группу `web_developer`? Кто из них является администратором группы?
    * Какой пользователь не может войти в систему?
    * Какой пользователь должен изменить пароль при следующем входе в систему?
    * Сколько дней должно пройти, прежде чем потребуется смена пароля для `carol`?

### Исследовательские упражнения <a href="#sec.5.2_01-ee" id="sec.5.2_01-ee"></a>

1. Работая от имени пользователя root, выполните команду `useradd -m dave` для добавления новой учётной записи пользователя. Какие операции выполняет эта команда? Предположим, что `CREATE_HOME` и `USERGROUPS_ENAB` в `/etc/login.defs` установлены на значение yes.
2. Теперь, когда вы создали учётную запись `dave`, сможет ли этот пользователь войти в систему?
3. Определите идентификатор пользователя (UID) и идентификатор группы (GID) `dave` и всех участников группы `dave`
4. Создайте группы `sys_admin`, `web_admin` и `db_admin` и определите их идентификаторы (GID).
5. Добавьте новую учётную запись пользователя с именем `carol` и UID 1035 и установите `sys_admin` в качестве основной группы, а `web_admin` и `db_admin` — в качестве дополнительных групп.
6. Удалите учётные записи `dave` и `carol` пользователей, а также группы `sys_admin`, `web_admin` и `db_admin` пользователей, которые вы создали ранее.
7. Выполните команду `ls -l /etc/passwd /etc/group /etc/shadow /etc/gshadow` и опишите полученный результат с точки зрения прав доступа к файлам. Какие из этих четырёх файлов скрыты по соображениям безопасности? Предположим, что в вашей системе используются скрытые пароли.
8. Выполните команду `ls -l /usr/bin/passwd` . Какой специальный бит установлен и что он означает?

Создать новую учетную запись пользователя.

`groupadd`

Создать новую учетную запись группы.

`userdel`

Удалить учетную запись пользователя.

`groupdel`

Удалить учетную запись группы.

`passwd`

Изменить пароль учетных записей пользователей и контролировать все аспекты пароля.

## Ответы на упражнения с Руководством <a href="#sec.5.2_01-age" id="sec.5.2_01-age"></a>

1. Для каждой из следующих записей укажите файл, к которому она относится:
   *   `developer:x:1010:frank,grace,dave`

       `/etc/group`
   *   `root:x:0:0:root:/root:/bin/bash`

       `/etc/passwd`
   *   `henry:$1$.AbCdEfGh123456789A1b2C3d4.:18015:20:90:5:30::`

       `/etc/shadow`
   *   `henry:x:1000:1000:User Henry:/home/henry:/bin/bash`

       `/etc/passwd`
   *   `staff:!:dave:carol,emma`

       `/etc/gshadow`
2.  Обратите внимание на следующие выходные данные, чтобы ответить на следующие семь вопросов:

    ```sh
    # cat /etc/passwd | tail -3
    dave:x:1050:1050:User Dave:/home/dave:/bin/bash
    carol:x:1051:1015:User Carol:/home/carol:/bin/sh
    henry:x:1052:1005:User Henry:/home/henry:/bin/tcsh
    # cat /etc/group | tail -3
    web_admin:x:1005:frank,emma
    web_developer:x:1010:grace,kevin,christian
    dave:x:1050:
    # cat /etc/shadow | tail -3
    dave:$6$AbCdEfGh123456789A1b2C3D4e5F6G7h8i9:0:20:90:7:30::
    carol:$6$q1w2e3r4t5y6u7i8AbcDeFgHiLmNoPqRsTu:18015:0:60:7:::
    henry:!$6$123456789aBcDeFgHa1B2c3d4E5f6g7H8I9:18015:0:20:5:::
    # cat /etc/gshadow | tail -3
    web_admin:!:frank:frank,emma
    web_developer:!:kevin:grace,kevin,christian
    dave:!::
    ```

    *   Каков идентификатор пользователя (UID) и идентификатор группы (GID) `carol`?

        UID равен 1051, а GID равен 1015 (третье и четвёртое поля в `/etc/passwd`).
    *   Какая оболочка установлена для `dave` и `henry`?

        `dave` используется /bin/bash, а `henry` использует /bin/tcsh (седьмое поле в `/etc/passwd`).
    *   Как называется основная группа `henry`?

        Название группы - `web_admin` (первое поле в `/etc/group`).
    *   Кто входит в группу `web_developer`? Кто из них является администратором группы?

        Участниками являются `grace`, `kevin` и `christian` (четвертое поле в `/etc/group`), но только `kevin` является администратором группы (третье поле в `/etc/gshadow`).
    *   Какой пользователь не может войти в систему?

        Учетная запись `henry` пользователя заблокирована (перед хешами пароля в `/etc/shadow` стоит восклицательный знак).
    *   Какой пользователь должен изменить пароль при следующем входе в систему?

        Если в третьем поле (Дата последнего изменения пароля) в `/etc/shadow` указано 0, пользователь должен изменить свой пароль при следующем входе в систему. Поэтому `dave` должен изменить свой пароль.
    *   Сколько дней должно пройти, прежде чем потребуется смена пароля для `carol`?

        60 дней (пятое поле в `/etc/shadow`).

### Ответы на исследовательские упражнения <a href="#sec.5.2_01-aee" id="sec.5.2_01-aee"></a>

1.  Работая от имени пользователя root, выполните команду `useradd -m dave` для добавления новой учётной записи пользователя. Какие операции выполняет эта команда? Предположим, что `CREATE_HOME` и `USERGROUPS_ENAB` в `/etc/login.defs` установлены на значение yes.

    Команда добавляет нового пользователя с именем `dave` в список пользователей системы. Создаётся домашний каталог `dave` (по умолчанию `/home/dave`), а файлы и каталоги, содержащиеся в каталоге-скелете, копируются в домашний каталог. Наконец, создаётся новая группа с тем же именем, что и учётная запись пользователя.
2.  Теперь, когда вы создали учётную запись `dave`, сможет ли этот пользователь войти в систему?

    Нет, потому что аккаунт `dave` заблокирован (см. восклицательный знак в `/etc/shadow`).

    ```sh
    cat /etc/shadow | grep dave
    dave:!:18015:0:99999:7:::
    ```

    Если вы установите пароль для `dave`, учётная запись будет разблокирована. Это можно сделать с помощью команды `passwd`

    ```sh
    # passwd dave
    Changing password for user dave.
    New UNIX password:
    Retype new UNIX password:
    passwd: all authentication tokens updated successfully.
    ```
3.  Определите идентификатор пользователя (UID) и идентификатор группы (GID) `dave` и всех участников группы `dave`

    ```sh
    # cat /etc/passwd | grep dave
    dave:x:1015:1019::/home/dave:/bin/sh
    # cat /etc/group | grep 1019
    dave:x:1019:
    ```

    UID и GID `dave` равны 1015 и 1019 соответственно (третье и четвёртое поля в `/etc/passwd`), а в группе `dave` нет участников (четвёртое поле в `/etc/group` пусто).
4.  Создайте группы `sys_admin`, `web_admin` и `db_admin` и определите их идентификаторы (GID).

    ```sh
    # groupadd sys_admin
    # groupadd web_admin
    # groupadd db_admin
    # cat /etc/group | grep admin
    sys_admin:x:1020:
    web_admin:x:1021:
    db_admin:x:1022:
    ```

    Идентификаторами GID для групп `sys_admin`, `web_admin` и `db_admin` являются 1020, 1021 и 1022 соответственно.
5.  Добавьте новую учётную запись пользователя с именем `carol` и UID 1035 и установите `sys_admin` в качестве основной группы, а `web_admin` и `db_admin` — в качестве дополнительных групп.

    ```sh
    # useradd -u 1035 -g 1020 -G web_admin,db_admin carol
    # id carol
    uid=1035(carol) gid=1020(sys_admin) groups=1020(sys_admin),1021(web_admin),1022(db_admin
    ```
6.  Удалите учётные записи `dave` и `carol` пользователей, а также группы `sys_admin`, `web_admin` и `db_admin` пользователей, которые вы создали ранее.

    ```sh
    # userdel -r dave
    # userdel -r carol
    # groupdel sys_admin
    # groupdel web_admin
    # groupdel db_admin
    ```
7.  Выполните команду `ls -l /etc/passwd /etc/group /etc/shadow /etc/gshadow` и опишите полученный результат с точки зрения прав доступа к файлам. Какие из этих четырёх файлов скрыты по соображениям безопасности? Предположим, что в вашей системе используются скрытые пароли.

    ```sh
    # ls -l /etc/passwd /etc/group /etc/shadow /etc/gshadow
    -rw-r--r-- 1 root root    853 mag  1 08:00 /etc/group
    -rw-r----- 1 root shadow 1203 mag  1 08:00 /etc/gshadow
    -rw-r--r-- 1 root root   1354 mag  1 08:00 /etc/passwd
    -rw-r----- 1 root shadow 1563 mag  1 08:00 /etc/shadow
    ```

    Файлы `/etc/passwd` и `/etc/group` доступны для чтения всем пользователям и скрыты по соображениям безопасности. При использовании скрытых паролей во втором поле этих файлов вы увидите `x`, потому что зашифрованные пароли пользователей и групп хранятся в `/etc/shadow` и `/etc/gshadow`, которые доступны для чтения только пользователю root, а в некоторых системах — также членам группы `shadow`
8.  Выполните команду `ls -l /usr/bin/passwd` . Какой специальный бит установлен и что он означает?

    ```sh
    # ls -l /usr/bin/passwd
    -rwsr-xr-x 1 root root 42096 mag 17 2015 /usr/bin/passwd
    ```

    В команде `passwd` установлен бит SUID (четвёртый символ в этой строке), что означает, что команда выполняется с правами владельца файла (то есть root). Так обычные пользователи могут изменить свой пароль.
