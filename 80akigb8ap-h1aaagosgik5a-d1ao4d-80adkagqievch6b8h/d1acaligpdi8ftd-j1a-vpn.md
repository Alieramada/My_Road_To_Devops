# Подключение к vpn

Серверная часть работает под [SoftEther VPN server](https://habr.com/ru/articles/566650/)

Подключение возможно как openvpn, так и по [ipsec/l2tp](https://www.softether.org/5-download)

Для подключения, в зависимости от вашего устройства и ОС, можно использовать либо встроенные пакеты, либо ПО [https://www.softether.org/5-download](https://www.softether.org/5-download).

Зарегестрировать у системного администратора вашу учётную запись.

Для openvpn получить файл конфигурации, логин, пароль/сертефикат.

Для ipsec/l2tp получить общий ключ, логин, пароль/сертефикат.



Подключение l2tp ос Linux

Установить необходимые пакеты для [ipsec/l2tp](https://www.softether.org/5-download) (network-manager-l2tp) и для графической среды, ( в случае гнома network-manager-l2tp-gnome)
