## Поворот страницы PDF

В этом разделе мы рассмотрим, как поворачивать PDF-страницы. Для этого мы будем использовать метод rotate.Clockwise() объекта PDF. Создайте скрипт с именем rotate\_pdf.py и запишите в него следующее содержимое:

```python
import PyPDF2

with open('test.pdf', 'rb') as pdf:
    rd_pdf = PyPDF2.PdfFileReader(pdf)
    wr_pdf = PyPDF2.PdfFileWriter()
    for pg_num in range(rd_pdf.numPages):
        pdf_page = rd_pdf.getPage(pg_num)
        pdf_page.rotateClockwise(90)
        wr_pdf.addPage(pdf_page)

    with open('rotated.pdf', 'wb') as pdf_out:
        wr_pdf.write(pdf_out)

print("pdf successfully rotated")
```

Запустите скрипт, и вы получите следующий результат:

```bash
student@ubuntu:~/work$ python3 rotate_pdf.py
```

Ниже приведены выходные данные:

```bash
pdf successfully rotated
```

В предыдущем примере для поворота pdf-файла мы сначала создали объект для чтения pdf-файлов из исходного pdf-файла. Затем повернутые страницы будут записаны в новый pdf-файл. Итак, для записи в новый pdf-файл мы используем функцию PdfFileWriter() модуля PyPDF2. Новый pdf-файл будет сохранен с именем rotated.pdf. Теперь мы повернем страницы pdf-файла, используя метод rotate.Clockwise(). Затем, используя метод addPage(). Теперь нам нужно записать эти pdf-страницы в новый pdf-файл. Итак, сначала мы должны открыть новый файловый объект (pdf\_out) и записать в него pdf-страницы, используя метод write() объекта pdf writer. После всего этого мы собираемся закрыть исходный файловый объект (test.pdf) и новый файловый объект (pdf\_out).

## Работа с файлами CSV

&#x20;Формат CSV обозначает значения, разделенные запятыми. Запятые используются для разделения полей в записи. Они обычно используются для импорта и экспорта формата электронных таблиц и баз данных.

CSV-файл - это обычный текстовый файл, который использует определенный тип структурирования для упорядочения табличных данных. В Python есть встроенный модуль csv, который позволяет Python анализировать файлы такого типа. Модуль csv в основном может использоваться для работы с данными, которые экспортируются из электронных таблиц, а также баз данных в формате текстовых файлов, с полями и записями.

В модуль csv встроены все необходимые функции, а именно:

* csv.reader: Эта функция используется для возврата объекта reader, который выполняет итерацию по строкам CSV-файла
* &#x20;csv.writer: Эта функция используется для возврата объекта writer, который записывает данные в CSV-файл&#x20;
* csv.register\_dialect: Эта функция используется для регистрации диалекта CSV
* &#x20;csv.unregister\_dialect: Это функция используется для отмены регистрации диалекта CSV csv.
* get\_dialect: Эта функция используется для возврата диалекта с заданным именем&#x20;
* csv.list\_dialects: Эта функция используется для возврата всех зарегистрированных диалектов
* &#x20;csv.field\_size\_limit: Эта функция используется для возврата текущего максимального размера поля, разрешенного синтаксическим анализатором&#x20;

В этом разделе мы рассмотрим только csv.reader и csv.writer.

## Запись в CSV-файл

Для записи данных в csv-файл мы используем модуль csv.writer. В этом разделе мы сохраним некоторые данные в списке Python, а затем поместим эти данные в csv-файл. Создайте скрипт с именем csv\_write.py и запишите в него следующее содержимое:

## Работа с текстовыми файлами

Обычный текстовый файл используется для хранения данных, которые представляют собой только символы или строки и не содержат каких-либо структурированных метаданных. В Python нет необходимости импортировать какие-либо внешние библиотеки для чтения и записи текстовых файлов. Python предоставляет встроенную функцию для создания, открытия, закрытия, а также записи и чтения текстовых файлов. Для выполнения этих операций существуют различные режимы доступа, которые определяют тип операций, возможных в открытом файле.

Режимы доступа в Python следующие:

* Режим только для чтения ('r'): В этом режиме открывается текстовый файл. Если этот файл не существует, возникает ошибка ввода-вывода. Мы также можем назвать этот режим режимом по умолчанию, в котором будет открыт файл.&#x20;
* Режим чтения и записи ('r+'): Этот режим открывает текстовый файл как для чтения, так и для записи и выдает ошибку ввода-вывода, если файл не существует.&#x20;
* Режим только для записи ('w'): Этот режим открывает текстовый файл для записи. Он создает файл, если он не существует, и для существующего файла данные перезаписываются.&#x20;
* Режим записи и чтения ("w+"): В этом режиме будет открыт текстовый файл для чтения и записи. Для существующего файла данные будут перезаписаны.&#x20;
* Режим только добавления ("a"): В этом режиме будет открыт текстовый файл для записи. Он создает файл, если файл не существует, и данные будут вставлены в конец существующих данных.&#x20;
* Режим добавления и чтения ('a+'): В этом режиме текстовый файл будет открыт как для чтения, так и для записи. Он создает файл, если он не существует, и данные будут вставлены в конец существующих данных.

## Вопросы

1. В чем разница между readline() и readlines() ?

В Python методы `readline()` и `readlines()` используются для чтения данных из файла.

**`readline()`** — этот метод считывает одну строку из файла и возвращает её в виде строки. Он может быть полезен, когда нужно прочитать файл построчно или обработать каждую строку отдельно. Например, если у вас есть большой текстовый файл, вы можете использовать `readline()`, чтобы прочитать первую строку, затем вторую и так далее.

**`readlines()`** — этот метод читает весь файл и возвращает список, содержащий все строки файла. Каждая строка в списке является отдельной строкой файла. Это может быть полезно, если вам нужно обработать весь файл сразу или если вы хотите выполнить операции строк файла.

Таким образом, основное различие между `readline()` и `readlines()` заключается в том, что первый метод считывает только одну строку за раз, а второй метод считывает весь файл и создаёт список строк.

2. В чем разница между open() и with open()?

Функция **`open()`** в Python используется для открытия файла и возвращает файловый объект. С её помощью можно читать, записывать или выполнять другие операции с файлом.

Конструкция **`with open() as`** автоматически закрывает файл после выполнения блока кода. Это обеспечивает правильное закрытие файла, даже если во время выполнения блока произошла ошибка. Использование этой конструкции считается более безопасным и предпочтительным способом работы с файлами в Python.

3. В чем значение r c:\Downloads при запуске?

Строка «r c:\Downloads» в начале кода обозначает, что будет открыт доступ для чтения к файлу или папке, которая находится в каталоге «c:\Downloads». Буква «r» указывает на то, что файл открывается только для чтения.

4. Что такое объект генератор

Генератор в Python — это функция, которая может приостанавливать своё выполнение и возвращать значения одно за другим, не сохраняя их все в памяти одновременно. Это позволяет эффективно работать с большими объёмами данных и экономить ресурсы.

Генераторы создаются с использованием ключевого слова `yield`. Когда функция встречает `yield`, она возвращает значение, но сохраняет своё состояние, чтобы продолжить выполнение с того же места при следующем вызове.

Пример генератора:

```
def my_generator():
    for i in range(5):
        yield i

# Создание генератора
my_gen = my_generator()

# Итерация по генератору
for num in my_gen:
    print(num)
```

5. Для чего используется pass?

Pass — это оператор в Python, который используется для обозначения пустого блока кода. Он не выполняет никаких операций и обычно используется как заполнитель или заглушка, когда требуется синтаксически корректный блок, но не нужно никакого реального действия или выражения.

Например, pass может быть использован в условных операторах (if, while и т. д.) или в циклах для создания пустых блоков кода, которые могут быть заполнены позже. Это помогает поддерживать структуру программы и делает код более читаемым.

6. Что такое лямбда-выражение?

**Лямбда-выражение** в Python — это короткий способ создания анонимной функции, то есть функции без имени. Оно состоит из ключевого слова `lambda`, за которым следуют аргументы функции, двоеточие и выражение.

Пример использования лямбда-функции:

```python
add = lambda x, y: x + y
result = add(3, 5)
print(result) # Вывод: 8
```

Здесь мы создали анонимную функцию с именем `add`, которая принимает два аргумента `x` и `y` и возвращает их сумму. Затем мы присвоили результат вызова этой функции переменной `result` и вывели его на экран.

Лямбда-функции особенно полезны в ситуациях, когда нужно создать простую функцию для однократного использования или передать её в качестве аргумента другой функции.
