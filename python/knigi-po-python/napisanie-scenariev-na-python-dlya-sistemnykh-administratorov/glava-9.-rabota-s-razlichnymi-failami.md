## Работа с файлами PDF

## Чтение PDF-документа и определение количества страниц

В этом разделе мы собираемся прочитать PDF-файл с помощью модуля PyPDF2. Кроме того, мы собираемся узнать количество страниц в этом PDF-файле. В этом модуле есть функция чтения PdfFileReader(), которая помогает при чтении PDF-файла. Убедитесь, что в вашей системе есть PDF-файл. В данный момент в моей системе присутствует файл test.pdf, поэтому я буду использовать этот файл в этом разделе. Введите имя вашего PDF-файла вместо test.pdf. Создайте скрипт с именем read\_pdf.py и напишите в нем следующее содержимое:

```python
import PyPDF2

with open('test.pdf', 'rb') as pdf:
    read_pdf= PyPDF2.PdfFileReader(pdf)
    print("Number of pages in pdf : ", read_pdf.numPages)
```

Запустите скрипт, и вы получите следующий результат:

```bash
student@ubuntu:~/work$ python3 read_pdf.py
```

Ниже приведены выходные данные:

```bash
Number of pages in pdf :  20
```

В предыдущем примере мы использовали модуль PyPDF2. Далее мы создали объект pdf-файла. Программа чтения PdfFileReader() прочитает созданный объект. После прочтения PDF-файла мы получим количество страниц в этом pdf-файле, используя свойство NumPages. В данном случае это 20 страниц.

## Поворот страницы PDF

В этом разделе мы рассмотрим, как поворачивать PDF-страницы. Для этого мы будем использовать метод rotate.Clockwise() объекта PDF. Создайте скрипт с именем rotate\_pdf.py и запишите в него следующее содержимое:

```python
import PyPDF2

with open('test.pdf', 'rb') as pdf:
    rd_pdf = PyPDF2.PdfFileReader(pdf)
    wr_pdf = PyPDF2.PdfFileWriter()
    for pg_num in range(rd_pdf.numPages):
        pdf_page = rd_pdf.getPage(pg_num)
        pdf_page.rotateClockwise(90)
        wr_pdf.addPage(pdf_page)

    with open('rotated.pdf', 'wb') as pdf_out:
        wr_pdf.write(pdf_out)

print("pdf successfully rotated")
```

Запустите скрипт, и вы получите следующий результат:

```bash
student@ubuntu:~/work$ python3 rotate_pdf.py
```

Ниже приведены выходные данные:

```bash
pdf successfully rotated
```

В предыдущем примере для поворота pdf-файла мы сначала создали объект для чтения pdf-файлов из исходного pdf-файла. Затем повернутые страницы будут записаны в новый pdf-файл. Итак, для записи в новый pdf-файл мы используем функцию PdfFileWriter() модуля PyPDF2. Новый pdf-файл будет сохранен с именем rotated.pdf. Теперь мы повернем страницы pdf-файла, используя метод rotate.Clockwise(). Затем, используя метод addPage(). Теперь нам нужно записать эти pdf-страницы в новый pdf-файл. Итак, сначала мы должны открыть новый файловый объект (pdf\_out) и записать в него pdf-страницы, используя метод write() объекта pdf writer. После всего этого мы собираемся закрыть исходный файловый объект (test.pdf) и новый файловый объект (pdf\_out).

## Чтение файла Excel

В этом разделе мы рассмотрим, как читать файл Excel. Мы собираемся использовать модуль xlrd. Создайте скрипт с именем read\_excel.py и запишите в него следующее содержимое:

```python

```

```

Ниже приведены выходные данные:

```

В предыдущем примере мы импортировали модуль xlrd для чтения файла Excel. Мы также указали местоположение файла Excel. Затем мы создали файловый объект, затем указали значение индекса, чтобы чтение начиналось с этого индекса. Наконец, мы распечатали результаты.

## Чтение определенных столбцов в файле Excel

Когда мы используем модуль pandas для чтения файла Excel с помощью метода read\_excel, мы также можем прочитать определенные столбцы в этом файле. Для чтения определенных столбцов нам нужно использовать параметр usecols в методе read\_excel.

Теперь давайте рассмотрим пример чтения определенных столбцов в файле Excel. Создайте скрипт с именем rd\_excel\_pandas1.py и запишите в него следующее содержимое:

```bash
import pandas as pd

excel_file = 'sample.xlsx'
cols = [1, 2, 3]
df = pd.read_excel(excel_file , sheet_names='sheet1', usecols=cols)

print(df.head())
```

Запустите предыдущий скрипт, и вы получите следующий результат:

```
student@ubuntu:~/test$ python3 rd_excel_pandas1.py
```

Ниже приведены выходные данные:

```bash

0  Central    Smith    Desk
1  Central   Kivell    Desk
2  Central     Gill  Pencil
3  Central  Jardine  Binder
4  Central  Andrews  Pencil
```

В предыдущем примере мы сначала импортировали модуль pandas. Затем мы создали строку с именем excel\_file для хранения имени файла. Затем мы определили переменную cols и поместили в нее значения индексов столбцов. Итак, когда мы использовали метод read\_excel, в рамках этого метода мы также предоставили параметр usecols для извлечения определенного столбца через индекс, который мы определили ранее в переменной cols. Таким образом, после запуска скрипта мы получаем только определенные столбцы из файла Excel.
