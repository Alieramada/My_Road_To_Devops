## Использование модуля os для работы с каталогами&#x20;

Каталог или папка - это набор файлов и подкаталогов. Модуль os предоставляет различные функции, которые позволяют нам взаимодействовать с операционной системой. В этом разделе мы узнаем о некоторых функциях, которые можно использовать при работе с каталогами.

## Получить рабочий каталог&#x20;

Чтобы начать работу с каталогами, сначала мы получим название нашего текущего рабочего каталога. В модуле os есть функция getcwd(), с помощью которой мы можем получить текущий рабочий каталог. Запустите консоль python3 и введите следующие команды, чтобы получить имя каталога:

```python
$ python3
Python 3.6.5 (default, Apr  1 2018, 05:46:30) 
[GCC 7.3.0] on linux
Type "help", "copyright", "credits" or "license" for more information.
>>> import os
>>> os.getcwd()
'/home/student'
>> 
```

## Изменение каталога

Используя модуль os, мы можем изменить текущий рабочий каталог. Для этого в модуле os есть функция chdir(), например:

```bash
>>> os.chdir('/home/student/work')
>>> print(os.getcwd())
/home/student/work
>>> 
```

## Копирование, перемещение, переименование и удаление данных

Мы познакомимся с четырьмя основными операциями, которые системные администраторы выполняют с данными: копированием, перемещением, переименованием и удалением. В Python есть встроенный модуль под названием shutil, который может выполнять эти задачи. Используя модуль shutil, мы также можем выполнять высокоуровневые операции с данными. Чтобы использовать модуль shutil в вашей программе, просто напишите инструкцию import shutil. Модуль shutil предлагает несколько функций, которые поддерживают операции копирования и удаления файлов. Давайте рассмотрим эти операции одну за другой.

## Копирование данных

В этом разделе мы увидим, как мы можем копировать файлы с помощью модуля shutil. Для этого сначала мы создадим файл hello.py и введем в него некоторый текст.

```python
hello.py:

print ("")
print ("Hello World\n")
print ("Hello Python\n")
```

Теперь мы напишем код для копирования в скрипт shutil\_copy\_example.py. Запишем в него следующее содержимое:

```python
import shutil
import os
shutil.copy('hello.py', 'welcome.py')
print("Copy Successful")
```

Запустите скрипт следующим образом:

```sh
$ python3 shutil_copy_example.py

Output:
Copy Successful
```

Проверьте наличие скрипта welcome.py, и вы увидите, что содержимое hello.py успешно скопировано в welcome.py.

## Перемещение данных

Мы увидим, как мы можем переместить данные. Для этой цели мы будем использовать shutil.move(). shutil.move(источник, пункт назначения) переместит файл из источника в пункт назначения. Теперь мы создадим shutil\_move\_example.py скрипт и запишем в него следующее содержимое:

```python
import shutil
shutil.move('/home/student/sample.txt', '/home/student/Desktop/.')
```

Запустите скрипт следующим образом:

```sh
$ python3 shutil_move_example.py
```

В этом скрипте нам нужно переместить файл sample.txt, который находится в каталоге /home/student. /home/student - это наша исходная папка, а /home/student/Desktop - наша целевая папка. Итак, после запуска скрипта sample.txt будет перемещен из каталога /home/student в каталог /home/student/Desktop.

## Переименование данных

В предыдущем разделе мы узнали, как можно использовать shutil.move() для перемещения файлов из источника в место назначения. С помощью shutil.move() файлы можно переименовывать. Создайте скрипт shutil\_rename\_example.py и запишите в него следующее содержимое:

```python
import shutil
```

```sh

```

Теперь убедитесь, что ваше имя файла будет переименовано hello\_renamed.py.

Теперь мы познакомимся с методом os.path(). Он используется для манипулирования путями. В этом разделе мы рассмотрим некоторые функции, которые модуль os предлагает для путей.

```python
>>> os.path.isfile('/home/student/work/sample.txt')
```


Pandas - это библиотека анализа данных с открытым исходным кодом, которая предоставляет структуры данных и простые в использовании инструменты анализа данных. Это упрощает импорт и анализ данных.

Создайте содержимое файла student1.csv следующим образом:

Теперь мы создадим compare\_data.py скрипт и запишем в него следующее содержимое:

```python
print (pd.DataFrame(list(s1.difference(s2))), '\n')
print (pd.DataFrame(list(s2.difference(s1))), '\n')
```

В предыдущем примере мы сравниваем данные из двух csv-файлов: student1.csv и student2.csv. Сначала мы преобразовали наши фреймы данных (df1, df2) в наборы (s1, s2). ## Файлы и каталоги, соответствующие шаблону

В этом разделе мы узнаем о сопоставлении шаблонов для файлов и каталогов. В Python есть модуль glob, который используется для поиска имен файлов и каталогов, соответствующих определенным шаблонам.

Теперь мы рассмотрим пример. Сначала создайте скрипт pattern\_match.py и напишите в нем следующее содержимое:

```python
import glob
file_match = glob.glob('*.txt')
print(file_match)
file_match = glob.glob('[0-9].txt')
print(file_match)
file_match = glob.glob('**/*.txt', recursive=True)
print(file_match)
file_match = glob.glob('**/', recursive=True)
print(file_match)
```

Запустите скрипт:

```
$ python3 pattern_match.py

Output:
['file1.txt', 'filea.txt', 'fileb.txt', 'file2.txt', '2.txt', '1.txt', 'file.txt']
['2.txt', '1.txt']
['file1.txt', 'filea.txt', 'fileb.txt', 'file2.txt', '2.txt', '1.txt', 'file.txt', 'dir1/3.txt', 'dir1/4.txt']
['dir1/']
```

В предыдущем примере мы использовали модуль Python glob для сопоставления с шаблоном. glob (pathname) вернет список имен, совпадающих с именем пути. В нашем скрипте мы передали три имени путей в трех разных функциях glob(). В первом glob() мы передали путь к файлу как \*.txt; это вернет все имена файлов с расширением .txt.

Во втором globe() мы передали \[0-9].txt; это вернет имена файлов, начинающиеся с цифры. В третьем globe() мы передали \*\*/\*.txt, который вернет имена файлов, а также имена каталогов. Он также вернет имена файлов из этих каталогов. В четвертом globe() мы передали \*\*/, который будет возвращать только имена каталогов.

## Метаданные: данные о данных

В этом разделе мы познакомимся с модулем pyPdf, который помогает извлекать метаданные из pdf-файла. Но сначала разберемся, что такое метаданные? Метаданные - это данные о данных. Метаданные - это структурированная информация, которая описывает первичные данные. Метаданные - это краткое изложение этих данных. Он содержит основную информацию о ваших фактических данных. Он помогает найти конкретный экземпляр ваших данных.

{% hint style="info" %}
Убедитесь, что в вашем каталоге есть pdf-файл, из которого вы хотите извлечь информацию.

Во-первых, мы должны установить модуль pyPdf следующим образом:

```bash
pip install pyPdf
```

Теперь мы напишем скрипт metadata\_example.py и посмотрим, как мы получим из него информацию о метаданных. Мы собираемся написать этот скрипт на Python 2:

```python
import pyPdf
def main():
            file_name = '/home/student/sample_pdf.pdf'
            pdfFile = pyPdf.PdfFileReader(file(file_name,'rb'))
            pdf_data = pdfFile.getDocumentInfo()
            print ("----Metadata of the file----")
            for md in pdf_data:
                        print (md+ ":" +pdf_data[md])
if __name__ == '__main__':
            main()
```

Запустите скрипт:

```bash

/CreationDate:D:19980930143358
```

В предыдущем сценарии мы использовали модуль pyPdf в Python 2. Сначала мы создали переменную file\_name, в которой хранится путь к нашему pdf-файлу. Данные считываются с помощью функции чтения PdfFileReader(). Переменная pdf\_data будет содержать информацию о вашем pdf-файле. Наконец, мы написали цикл for для получения информации о метаданных.

## Использование модуля tarfile для создания TAR-архивов

Этот раздел поможет вам узнать о том, как мы можем создавать tar-архивы с помощью модуля tarfile в Python.

Модуль tarfile используется для чтения и записи tar-архивов с использованием методов сжатия gzip, bz2. Убедитесь, что необходимые файлы и каталоги присутствуют. Теперь создайте скрипт tarfile\_example.py и напишите в нем следующее содержимое:

```python
import tarfile
tar_file = tarfile.open("work.tar.gz", "w:gz")
for name in ["welcome.py", "hello.py", "hello.txt", "sample.txt", "sample1.txt"]:
            tar_file.add(name)
tar_file.close()
```

Запустите скрипт:

```sh
$ python3 tarfile_example.py
```

Теперь проверьте ваш текущий рабочий каталог; вы увидите, что work.tar.gz был создан.

1. Как работать с разными путями независимо от разных ОС (Windows, Linux)?

Для работы с разными путями в Python независимо от операционной системы можно использовать несколько подходов. Вот некоторые из них:

**Использование модуля os.** Модуль os предоставляет функции для работы с операционной системой. Вы можете использовать его для получения текущего рабочего каталога, создания и удаления файлов и папок, а также для работы с путями.

**Использование кроссплатформенных инструментов.** В Python есть несколько библиотек, которые могут работать на разных операционных системах. Например, вы можете использовать библиотеку pathlib, которая предоставляет объектно-ориентированный интерфейс для работы с файлами и папками.

**Использование виртуальных сред.** Вы можете создать виртуальную среду с нужной версией Python и необходимыми библиотеками. Это позволит вам изолировать вашу работу от других проектов и избежать конфликтов версий.

**Использование контейнеров.** Контейнеры, такие как Docker, позволяют вам создавать изолированные среды для запуска приложений. Вы можете настроить контейнеры с нужными версиями Python и библиотеками и запускать их по мере необходимости.

**Использование сетевых файловых систем.** Вы можете использовать сетевые файловые системы, такие как NFS или SMB, для обмена файлами между разными ОС. Это позволит вам работать с файлами на разных машинах, не беспокоясь о различиях в путях.

**Использование облачных сервисов.** Облачные сервисы, такие как Google Cloud или Amazon Web Services, предоставляют вам доступ к ресурсам через веб-интерфейс. Вы можете использовать эти сервисы для работы с файлами и папками на разных ОС, не заботясь о различиях в путях.

Выбор подхода зависит от ваших конкретных потребностей и целей.

2. Какие разные аргументы доступны для print() в python?&#x20;

У функции print() в Python есть несколько аргументов, которые позволяют настроить вывод. Вот некоторые из них:

* **sep** — определяет разделитель между элементами вывода. По умолчанию используется пробел. Пример использования: print("Hello", "World", sep="").
* **end** — указывает символ, который будет добавлен после последнего элемента вывода. По умолчанию добавляется новая строка. Пример использования: print("Hello", end="\n").
* **file** — позволяет указать файл, в который будет записан вывод. Это может быть любой открытый файл. Пример использования: print("Hello", file=open("file.txt", "w")).
* **flush** — при значении True принудительно очищает буфер вывода. Пример использования: print("Hello", flush=True).
* **\*objects** — это необязательные аргументы, позволяющие вывести несколько объектов. Пример использования: print("Hello", 1, 2, 3).

Также с помощью форматирования строк можно использовать различные спецификаторы формата для вывода данных разных типов. Например, %s для строк, %d для целых чисел и %f для вещественных чисел.

Это лишь некоторые аргументы функции print(). Они могут быть полезны в различных ситуациях и позволяют гибко настраивать вывод данных.

4. Что такое фрейм данных, серия в pandas?

**Фрейм данных** — это двумерная структура данных, которая хранит информацию в виде столбцов и строк. Фреймы данных являются основным компонентом библиотеки pandas в Python и используются для хранения и обработки структурированных данных. Они позволяют выполнять различные операции над данными, такие как фильтрация, сортировка, агрегация и т. д.

**Серия** — это одномерный массив данных, который является основным строительным блоком фрейма данных. Серии могут хранить данные любого типа, включая числа, строки, даты и т. п. Они также поддерживают различные методы для выполнения операций над данными.

В библиотеке pandas фреймы данных и серии используются для анализа и обработки данных. Они предоставляют удобные инструменты для работы с большими объёмами данных и позволяют выполнять сложные операции над ними.

5. &#x20;Что такое **списковое включение списка**?&#x20;

**Понимание (или списковое включение) списка** — это конструкция в Python, которая позволяет создавать новые списки на основе существующих. Она представляет собой краткий и элегантный способ создания списков с использованием циклов и условных операторов.

Понимание списка состоит из квадратных скобок, внутри которых находится выражение, определяющее элементы списка, и цикл for для перебора элементов. Вот пример понимания списка:

```python
[выражение for переменная in список]
```

Здесь «выражение» определяет, как вычисляется каждый элемент списка, а «переменная» представляет текущий элемент списка.

Вот несколько примеров:

Создание списка квадратов чисел от 0 до 4:

```python
squares = [n**2 for n in range(5)]
print(squares) # Вывод: [0, 1, 4, 9, 16]
```

Фильтрация списка чисел, чтобы оставить только чётные числа:

```python
evens = [n for n in range(10) if n % 2 == 0]
print(evens) # Вывод: [0, 2, 4, 6, 8]
```

Преобразование списка строк в верхний регистр:

```python
uppercase = [s.upper() for s in ['Hello', 'World', 'Python']]
print(uppercase) # Вывод: ['HELLO', 'WORLD', 'PYTHON']
```

6. Можем ли мы использовать **списковое включение** набора и словаря? Если да, то как?

Да, мы можем использовать списковое включение для создания наборов и словарей в Python.

#### Создание набора с помощью спискового включения

Для создания набора с использованием спискового включения нужно поместить все элементы в фигурные скобки `{}` и перечислить их через запятую. Вот пример:

```python
my_set = {x for x in range(5)}
print(my_set)
```

Этот код создаст набор чисел от 0 до 4.

Также можно создать набор из существующих объектов, используя списковое включение:

```python
existing_list = [1, 2, 3, 4, 5]
my_set = {element for element in existing_list}
print(my_set)
```

В этом примере создаётся набор из уникальных элементов существующего списка `existing_list`.

#### Создание словаря с помощью спискового включения

Чтобы создать словарь с использованием спискового включения, нужно перечислить пары «ключ: значение» внутри фигурных скобок `{}`, разделив их запятыми. Вот пример создания словаря, где ключи — это имена сотрудников, а значения — их зарплаты:

```python
employees = ["Иван", "Мария", "Сергей"]
salaries = [50000, 60000, 70000]
employee_dict = {name: salary for name, salary in zip(employees, salaries)}
print(employee_dict)
```

Здесь используется функция `zip()` для объединения имён и зарплат в пары, которые затем используются для создания словаря.

Можно также создать словарь, используя существующие списки ключей и значений:

```python
keys = ["Имя", "Фамилия", "Должность"]
values = ["Иван", "Иванов", "Программист"]
my_dict = {key: value for key, value in zip(keys, values)}
print(my_dict)
```

Таким образом, списковое включение позволяет удобно создавать наборы и словари на основе существующих данных или вычисляемых значений.

7. Как напечатать первые/ последние N строк, используя pandas dataframe?

Чтобы напечатать первые N строк, используйте метод head(). Например, чтобы вывести первые 5 строк, напишите:

```python
dataframe.head(5)
```

Чтобы вывести последние N строк, воспользуйтесь методом tail(). Например, для вывода последних 5 строк напишите:

```python
dataframe.tail(5)
```

8. Написать программу, использующую списковое включение списка для печати нечетных чисел

```python
# Задаем диапазон, например от 1 до 20
start = 1
end = 20

# Используем списковое включение для создания списка нечетных чисел
odd_numbers = [num for num in range(start, end + 1) if num % 2 != 0]

# Печатаем нечетные числа
print("Нечетные числа в диапазоне от", start, "до", end, ":", odd_numbers)
```
